# M2 — локальная медиатека и воспроизведение

2026-09-09. Реализация: [ADR-003](DECISIONS/ADR-003-local-playback.md).

## Подтверждённые проверки

- `:core:test`, debug APK, test APK и `:app:lintDebug` проходят.
- Android 35 x86_64: [10 инструментальных тестов](qa/m2/instrumentation-phone.txt).
- Android TV 29 x86: [10 инструментальных тестов](qa/m2/instrumentation-tv.txt).
- В каждом наборе четыре новых сценария используют реальные разрешения SAF,
  отдельный DocumentsProvider в тестовом APK и Media3/ExoPlayer. Остальные шесть —
  регрессии UI M1 на явной debug DemoActivity (TV D-pad исполняется только на TV).
- Проверены рекурсивное чтение двух 30-секундных WAV, длительность и размер,
  Play/Pause/seek/next, foreground-уведомление, продвижение позиции при Activity в фоне, отсутствие
  самозапуска при смене профиля, восстановление после пересоздания Activity и сервиса.
- Ошибка доступа сохраняет записи недоступными; повторное подключение восстанавливает
  каталог. Удаление папки из индекса оставляет оригиналы доступными после нового grant.
- Повреждённый WAV вызывает понятную ошибку, исправный файл после него играет.

## Выдаваемый APK

Выдаваемая версия — **2.0.0beta-build3**, versionCode 3,
applicationId `dev.petrov.ymplayer2`. APK подписан отдельным ключом 2.x,
не debuggable, R8/resource shrinking включены, APK Signature Scheme v2 проверена.
SHA-256: `4e2c506576a3977c7b9827bd6fdd3ce32efb9b018e6dd5568ecbb79568aebd1b`.

На Android 35 в обычном DocumentsUI выбрана `Music/YM2-Test`, получено постоянное
разрешение чтения, два WAV появились в каталоге. Сборка обновлена с build2 на
build3 с сохранением папки и позиции. Затем именно build3 прошёл
[системный сценарий](qa/m2/release-playback.json): Play → Home → Media Pause →
Media Play → Media Next → пауза → force-stop → повторный запуск. Проверены
переход с первого файла на второй и восстановление его позиции без автозапуска.

[Service dump](qa/m2/service.txt) подтверждает `isForeground=true`, notification
1001, mediaPlayback; [AudioFlinger](qa/m2/audioflinger.txt) — активный аудиотрек
процесса приложения. [Плеер](qa/m2/player-release.png),
[папки](qa/m2/folders-release.png), [TV без DocumentsUI](qa/m2/tv-folder-picker.png).
Release также установлен и запущен на Android TV 29; там проверено сообщение
об отсутствующем выборе папки. Физический звук на устройстве этим не подтверждается.

**Build2 — отклонённый кандидат.** При финальной проверке обнаружено отсутствие
foreground-регистрации и уведомления. Исправлена явная регистрация сессии в сервисе,
добавлена проверка notification в instrumentation и foreground в системном сценарии.
После исправления оба набора из 10 тестов прошли повторно. Номер build2 не используется
повторно; его метаданные сохраняются с `rejected_missing_foreground_notification`.

RepoWise CLI обновил индекс без модельных запросов. Автоматическая проверка GitHub
включает JVM-тесты, debug/test APK и lint; физическое устройство и instrumentation
эмуляторов остаются отдельными локальными проверками.

## Границы этого этапа

Физические телефон/TV/K4811 и настоящий съёмный USB-накопитель не проверялись.
Эмуляторы запущены без вывода звука на хост: автоматизация проверяет работу
аудиодвижка и AudioTrack, а не субъективное качество звучания.

Android TV 29 в тестовой конфигурации не содержит обработчика OPEN_DOCUMENT_TREE.
На таком устройстве нужен SAF-совместимый файловый менеджер; приложение выводит
объяснение. На Android 35 обычный DocumentsUI проверяется отдельно от test provider.

Каталог M2 — полный локальный снимок с ручным обновлением и проверкой при запуске.
Обход ограничен 5 000 папками и 50 000 записями на корень; превышение — ошибка
незавершённого обхода с сохранением предыдущего снимка. Масштабирование, пагинация,
перекрывающиеся выбранные деревья и автоматическое отслеживание hot-plug требуют
отдельного этапа. Обложки пока геометрические, пользовательских плейлистов нет.

После аварийного завершения позиция может отставать примерно на пять секунд.
Если часть сохранённой очереди недоступна, воспроизводимая очередь строится из
доступных файлов. Здесь ещё нет облачных аккаунтов или синхронизации профилей.

Яндекс, офлайн-кэш, клипы, SideBar, обновлятор и физическая приёмка остаются в плане.
Поэтому завершение локального сценария не снимает beta со всей версии 2.0.0.
