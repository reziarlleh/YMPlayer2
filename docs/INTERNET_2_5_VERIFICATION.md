# Интернет в сетевых разделах — текущая задача2.5

Уточнение владельца7 октября2026: при открытии клипов, Радио и Яндекс Музыки
дать5 секунд на подключение/восстановление. Если соединения нет, показать
«Отсутствует интернет» и «Повторить подключение». Локальные файлы/USB и
офлайн-кэш не должны зависеть от этой проверки.

## Реализация в работе

Core InternetConnection/InternetCheck отделяют источник доступности от
пятисекундного ожидания конкретного открытого экрана. Новый вход и Retry
начинают полное ожидание; восстановление до5 секунд отменяет сообщение.
Закрытие экрана отменяет check. Автоматический refresh каталога не включает
остановленное аудио; явный Retry может повторить неудавшееся воспроизведение.

App наблюдает default connectivity для Wi-Fi/cellular/Ethernet/VPN.
Неподтверждённую системную отметку планируется дополнить короткой HTTPS-проверкой
доступности используемого сервиса без токена/пароля: блокировка системного probe
не должна ложным образом закрывать работающий Яндекс. API-ошибки при доступном
интернете по-прежнему различаются с отсутствием соединения.

Shell показывает единое сообщение в сетевых разделах; локальный/офлайн выбор
остаётся доступен. ClipControls получает тот же статус, сохраняет Back и позицию
клипа. Тексты переводятся во все восемь пакетов. Новые Gradle-модули не нужны.
