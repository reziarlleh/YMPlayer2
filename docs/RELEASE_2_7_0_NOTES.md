# YMPlayer2 2.7.0 — полный состав версии

Ручной кандидат **2.7.0-build136**,13 ноября2026. Публикация ещё не выполнена.
Этот список охватывает весь цикл2.7.0, включая изменения первого Build134.

- Поддержка Android6.0/API23 и новее одним универсальным APK для смартфонов,
  планшетов, Android TV и магнитол. Современный targetSDK36 сохранён.
- Совместимые системные вызовы для языков, наблюдения за интернетом,
  фоновых служб и уведомлений. Сохраняются все8 переводов и текущие функции.
- На старых прошивках обложки и аудиофайлы кэша проверяются доступными API;
  перенос кэша и экспорт MP3 сохраняют проверки целостности и свободного места.
  Имена экспортируемых файлов поддерживают Unicode без отсутствующего на6 API.
- Старые хранилища HTTPS-сертификатов дополнены официальными ISRG Root X1/X2.
  Проверка сертификатов, имени сервера и защищённого соединения сохранена.
- Обновление совместимо с установщиком Android6/7 и общим разрешением
  «Неизвестные источники». На8+ сохраняется отдельное разрешение источнику.
  APK подписан прежним ключом с v1+v2; данные существующих2.x сохраняются.
- Включено исправление ручного133: смахивание системной медиакарточки
  сохраняет трек, очередь волны и позицию без звука. Явная кнопка Stop
  приложения/TV по-прежнему очищает волну. Безусловный автозапуск не добавлен.

Проверки и их границы: [подробный отчёт](ANDROID6_2_7_0_VERIFICATION.md).
До отдельного разрешения владельца стабильный выпуск и автообновление —132.
