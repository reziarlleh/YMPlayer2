# M12.6 — build50 и обновление клиентом build49

Дата проверки: 2026-09-30. Выпущен подписанный
[`2.0.0beta-build50`](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.0.0beta-build50),
`applicationId=dev.petrov.ymplayer2`, `versionCode=50`.
В APK вошли M6.5, M11.6 и M11.7: короткий активный список волны,
отказ от второй полной копии локального каталога в последовательном режиме
и адресный запрос соседей при естественном переходе локального аудио.

## Проверено

- Release-сборка завершилась успешно; `Build-Release.ps1` проверил пакет,
  версию, отсутствие debug-флага и подпись. SHA-256 сертификата совпадает
  с build49: `fbc7f884d76568e5b5f7be16e83b4a39f1fedad334ebd0be7fba7aa0bea406ec`.
- Локальный APK и повторно скачанные APK GitHub Releases, закреплённого
  jsDelivr и Gcore имеют размер `4 721 926` байт и SHA-256
  `e8cc62dd34035ac39c7b030aeabea08e290a05e4721419049b8c90f5dc32912e`.
  На момент повторной проверки все три манифеста `main` показывали build50:
  [источники](qa/m12-6/source-hashes.txt). Эта проверка не имитирует недоступность
  GitHub в сети владельца и не доказывает конкретный выбранный CDN-узел.
- На Android 15 установленный build49 показал build50 и заметки:
  [предложение](qa/m12-6/offer-build50.png). Загрузка кнопкой приложения
  открыла [системный установщик](qa/m12-6/installer-build50.png).
  После подтверждения PackageManager показывает build50 с прежним
  `firstInstallTime=2026-09-09 07:09:25`:
  [до](qa/m12-6/before-package.txt), [после](qa/m12-6/after-package.txt).
  Приложение открылось после установки:
  [экран](qa/m12-6/after-upgrade.png), [UI](qa/m12-6/after-upgrade-ui.xml).
- В проверенном error-logcat нет `AndroidRuntime`, `FATAL EXCEPTION`
  и SQLite-ошибок. Предшествующие функциональные проверки исходников:
  [19 сценариев волны](M6_5_VERIFICATION.md), [локальное воспроизведение
  и регрессия](M11_7_VERIFICATION.md); `core:test` и `app:lintDebug` прошли.
  CI коммита M11.7 `acb148e` завершился успешно, run `36519165377`.

В переходе 49→50 использован прежний тестовый профиль без пользовательской
коллекции; сохранение содержимого коллекции этим прогоном не доказано.
Более ранняя проверка данных 40→41→42 описана в [M12.2](M12_2_VERIFICATION.md).
Клиент build49 против следующего опубликованного релиза теперь проверен
сквозным сценарием. Миграции, полная выпускная регрессия и независимая
приёмка сети владельца остаются открыты; M12 и stable 2.0.0 не завершены.
M11 ещё содержит полный снимок библиотеки и другие пути, перечисленные
в [M11.7](M11_7_VERIFICATION.md). Физические K4811/HyperOS не проверялись.
