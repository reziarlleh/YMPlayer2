# YMPlayer2 2.6.5-build125 — для проверки

Подписанная сборка для ручной установки поверх предыдущей2.x. Обычный канал
обновлений остаётся на **2.6.4-build124**. На GitHub этот APK опубликован как
предварительный выпуск для скачивания, без смены Latest и без суффикса beta
в версии приложения.

Изменения2.6.5:

- Обычная синхронизация офлайн-кэша докачивает недостающее без повторного чтения
  всего сохранённого аудио. Новые треки скачиваются первыми.
- Полная проверка содержимого вынесена в отдельную кнопку
  **Проверить и восстановить кэш**, с прогрессом и отменой.
- Исправлены обложки после переноса папки кэша и обновление картинки после
  восстановления файла по прежнему адресу. Ограничен размер декодирования.
- Новые подписи переведены на все восемь языков, обе инструкции дополнены.

Проверки кода:166 JVM,42 разных native-сценария Android9 и7 Android15,
release lint и CI. На тестовой коллекции1000+2 получено6,6–13,1s без чтения
готового аудио; источник двух новых треков локальный, скорость Интернета в замер
не входит. Подпись и идентификатор приложения сохранены.
