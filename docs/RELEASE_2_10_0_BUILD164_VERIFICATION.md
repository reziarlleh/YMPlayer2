# Проверки YMPlayer2 2.10.0-build164

В исправлении «Моей волны» давние повторы сразу допускаются в очередь в порядке рекомендаций Яндекса. Из выбора исключаются активная очередь, недавние повторы, заблокированные и недоступные треки. Порядок рекомендаций подтверждён сценарием, в котором допустимый давний трек предложен раньше нового. [Причина сбоя и промежуточный Build 163](MY_WAVE_HISTORY_RECOVERY_2026_11_28.md).

На Android 15 прошли 11 инструментальных сценариев. В тесте повторной выдачи второй трек начал готовиться сразу после одного запроса продолжения. Проверены восстановление «Моей волны», её настройки, выход из повторной выдачи сессии и запуск жанровой волны из поиска. TalkBack получает действие открытия на трёх свёрнутых ручках. Обычный свайп и автоскрытие сохраняют прежнее поведение. Экспорт MP3 также прошёл. Прошли 198 JVM-тестов ядра и сверка 840 сообщений во всех восьми языковых наборах.

Сценарии сетевого воспроизведения использовали тестовые ответы. Данные владельца и текущая выдача его аккаунта на эмуляторе не использовались.

Подписанный APK установлен поверх 2.10.0-build163 на Android 15. Сохранённый локальный трек и главный экран доступны после запуска. Сверены package name dev.petrov.ymplayer2, прежний сертификат, minSdk 23 и SHA-256 установленного APK. :app:lintRelease --offline завершился с 0 ошибок, 150 предупреждениями и прежними 110 UseKtx.
