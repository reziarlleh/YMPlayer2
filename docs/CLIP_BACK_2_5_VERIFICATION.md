# Возврат из клипов и автоматическая догрузка Радио — beta94

7 октября2026 владелец предварительно принял Радио93 («С радио всё ок.
Ещё протестирую»), затем прислал экран старой заглушки после Back из клипов
и указал лишнюю «Ещё станции» при уже автоматической догрузке карусели.

## Причина и исправление

ShellApp.navigate менял Compose route на clips перед запуском внешней
ClipActivity. После finish основное окно оставалось на старом MessageScreen.
На диске route=clips нужен для восстановления активного видеосеанса; он
не должен определять экран за Activity. Теперь shell сохраняет исходный
раздел, app хранит clips_return_route отдельно, Main использует shellRoute,
а enterClips/leaveClips устанавливают/возвращают persisted route.
Повторное создание ClipActivity не затирает return route. Старый checkpoint
без этого поля использует настоящий Player, а не заглушку.

Системный Back и кнопка видео идут через finish: клип сохраняет паузу,
музыка/радио сами не запускаются. После явного закрытия следующему Main
не предлагается повторно открыть клип. Production также нормализует прежний
SavedState Bundle с route=clips; demo без внешнего видеомодуля остаётся отдельным.
История действий не используется как универсальный стек вместо иерархии Back.

Из каруселей и CatalogStatus удалены ручные «Ещё станции». LazyRow/grid
догружают по позиции просмотра, как в93. При сетевой ошибке остаётся явный
Retry, без цикла повторных запросов. Controller/API/алгоритмы радио не менялись.
