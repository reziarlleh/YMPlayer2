# Пакет скина YMPlayer 2.1

Контракт `schemaVersion: 1`. Расширение `.ymskin`: обычный ZIP без пароля,
в корне `manifest.json` в UTF-8. Пакет содержит только визуальные данные.
Чтение выполняется без извлечения архива на диск.

Обязательные поля manifest: `schemaVersion`, `id`, `name`, `author`.
ID: 1–64 символа `[a-z0-9._-]`, начинается с буквы или цифры;
`prism` зарезервирован для встроенного «Оксида».
Название и автор: непустые строки до 80 символов. Необязательны `description`
(до 400), `dark`, `light`, `icons`, `artwork`.

`dark` и `light` — объекты с семантическими именами Material3 и значениями
`#RRGGBB`. Отсутствующие токены наследуются от «Оксида» соответствующего режима.
Допустимые имена перечислены в `SkinPackageReader.colorRoles`; неизвестные поля
считаются ошибкой, чтобы опечатка не приводила к молчаливой потере оформления.
Размеры, шрифты, команды, подписи и доступность элементов остаются в приложении.

`icons`: объект `UiIcon.name → относительный путь JSON`, например
`"PLAY": "icons/play.json"`. JSON-вектор содержит `width`, `height`
(viewport, положительные числа до 1024), `paths`: массив объектов
`{"data":"M 4 3 L 20 12 L 4 21 Z", "fillType":"nonZero"}`.
`fillType`: `nonZero` или `evenOdd`, по умолчанию `nonZero`.
Все пути залиты одним цветом, который UI окрашивает семантическим tint.
SVG можно использовать как источник атрибутов `d`; полный SVG, внешние ссылки,
скрипты, растровые файлы и шрифты не исполняются и не поддерживаются.
Отсутствующий значок получает встроенное изображение с той же ролью.
Пользовательский значок не меняет действие или область нажатия кнопки.

`artwork`: `backgrounds` (1–12 цветов) и `end` — палитра заглушек обложек.
Отсутствующий объект наследуется целиком от «Оксида».

Лимиты: архив до 1 MiB; суммарно распакованные данные до 2 MiB;
до 64 файлов, каждый до 256 KiB. Manifest до 64 KiB;
до 64 путей на значок, суммарная длина path data до 64 KiB.
Только относительные пути ASCII без пустых частей, `.`/`..`, обратных слешей,
повторяющихся имён и вложенных архивов. Неиспользуемые файлы запрещены.
Каталоги ZIP допускаются, но не извлекаются.

Импорт сначала проверяет весь пакет и показывает preview. Только «Применить»
сохраняет его и переключает оформление. Ошибка импорта сохраняет текущий скин.
Повреждённый сохранённый активный пакет при запуске заменяется «Оксидом» с
сообщением. Launcher/TV-плитка сохраняют официальный логотип; белые кнопки
K4811 остаются белыми. Полное руководство и шаблоны входят в M13.5.
