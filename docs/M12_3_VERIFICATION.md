# M12.3 — проверка автоматического предложения обновления

2026-09-28, после опубликованного `2.0.0beta-build47`. Нового APK этот этап
не выпускает.

`UpdateAutoOfferTest` запускает `MainActivity` на Android 15 с выключенной
реальной сетевой автопроверкой, затем передаёт `UpdateCoordinator` подставленный
HTTPS-манифест более нового build через `UpdateClient`. Подтверждено:

- `checkOnLaunch()` выставляет `offer` и `prompt` после чтения новой версии;
- второе открытие в пределах суток не делает запрос и не открывает диалог заново;
- выключенная автопроверка не обращается к манифесту;
- прежние настройки тест восстанавливает.

Проверка `:app:connectedDebugAndroidTest` для этого класса прошла: один тест
на `YM2_M1_Phone(AVD) - 15`. Это доказательство состояния координатора,
но не реального показа диалога поверх выпуска в сети владельца.

Дополнительно живые запросы с рабочего компьютера к GitHub Raw,
`cdn.jsdelivr.net` и `fastly.jsdelivr.net` вернули `2.0.0beta-build47`.
Это срез на момент запроса, не гарантия свежести CDN после следующей публикации
или доступности из сети владельца.

Открыто: UI-проверка предложения на опубликованном build после нового релиза,
доступность резервного источника в сети владельца, миграции и выпускная регрессия.
