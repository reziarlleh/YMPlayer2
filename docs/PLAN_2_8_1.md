системы профилей. База — принятый и опубликованный 2.8.0-build144. Фиксируется

## Цели

- [x] Общие/персональные настройки разделены: в общих «О приложении» первым,
  обновление предпоследним, диагностика последним; глобальные параметры кэша
  в середине. Язык/тема/скин/масштаб и папка/синхронизация кэша — внутри текущего
  профиля. Музыкальные папки устройства/USB остаются общими (подтверждено владельцем).
- [x] Индивидуальные стандартные/пользовательские каталоги Яндекс-профилей.
  Профили могут одновременно использовать разные виды хранилища; перенос,
  очистка и подключение одного не меняют другой.
- [x] Включение, Wi-Fi и качество остаются общими. При глобальном отключении
  индивидуальные папки недоступны для настройки/работы; прежние пути и файлы
  сохранены. Защита действует в контроллере/службе, не только в UI.
- [x] Версия переносимого описания с cacheId/UID, без токенов, локального UUID
  как условия совместимости и абсолютных ссылок внутри переносимых записей.
- [x] Миграция известных каталогов 144 на месте без повторного скачивания и
  потери размещения. Неизвестные корни не удаляются. При выключенном кэше
  преобразование отложено до включения.
- [x] Подключение копии нового формата после переустановки/на другом устройстве;
  распознавание legacy, предупреждение и выбор найденного набора, сверка лайков
  перед импортом. Разные UID/неподдерживаемая версия не перепривязываются молча.
- [x] Объединение совпадающего кэша без повторной загрузки исправного аудио;
  проверка места/контрольных сумм, сохранность исходного до фиксации результата,
  безопасное прерывание и повтор после смерти процесса.
- [x] D-008: удаление профиля очищает его внутренний кэш; внешний сохраняется
  для повторного подключения. Остальные профили и исходная локальная музыка
  не затрагиваются.
- [x] Все новые тексты на восьми языках; обе инструкции/карты/README/журналы
  описывают фактический результат и границы подтверждения.

## Проверка

Адресные JVM и native Android 6/API23 и современного API: разные профили/один
аккаунт, стандартное/SAF, реальная структура 144, чистая установка/копирование,
неверный UID/новая версия/чужие файлы, нехватка места/отзыв доступа, выключение
и смена профиля во время операции, отмена/восстановление. Проверка синхронизации
с повторным использованием аудио, очистка только своего корня, сохранность волны
и экспортов. Подписанная сборка прежним ключом и установка поверх 144 без очистки.
