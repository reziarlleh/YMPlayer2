# ADR-044 — внешняя папка кэша и отдельный экспорт MP3

Принято13 октября2026 для утверждённого этапа2.6.0.
[План](PLAN_2_6.md), [реализация/проверки](FILE_TRANSFERS_2_6_VERIFICATION.md).

Нельзя считать SAF-папку абсолютным File path или переименованием .audio
объявлять файл MP3. Поэтому File/SAF операции объединены в StorageNode,
а экспорт использует фактический MIME MediaExtractor и MediaCodec decoder.
Прежний формат кэша v1 и ключи profile/account/track сохраняются без миграции
логических данных. Меняется только корень размещения и публикуемые URI.

Перенос — copy/verify/commit/remove, не перемещение по одному файлу с ранним
удалением. Временный корень уникален; preferences/journal приватны. Commit
следует за проверкой всех файлов, исходное удаляется после переключения.
Location lease отделяет перенос от записи синхронизации; отдельный read/write
Mutex не удерживается на сетевых запросах, чтобы не замедлять выбор готового трека.
Извлечение USB не разрешает
заменить недоступный кэш пустой копией. Неизвестное свободное место запрещает
перенос/экспорт. Непрерывная офлайн-очередь во время переноса не гарантируется.

Экспортёр отделён от кэша и playback, выбирает конечную папку через SAF,
не создаёт постоянную копию альбомов/артистов. MP3 packet copy сохраняет аудио;
AAC/иные декодируемые источники локально преобразуются в MP3. Jump3r1.0.5
даёт Java encoder на всех ABI без NDK/новых native бинарников; цена — CPU
и потери повторного кодирования. Входные треки не заменяются preview.
Скачивание и выходной temp размещаются в выбранной папке, с проверками ёмкости.
В будущем encoder можно заменить за границей Mp3AudioWriter.
[Лицензия/исходники](THIRD_PARTY.md) включены в APK.

Шаблон — ограниченные стабильные переменные, не пути/скрипты. Подстановки
не повторяются внутри тегов трека; недопустимые символы удаляются из результата,
не из источника. Чужие файлы не перезаписываются. Общий foreground-сервис
сохраняет операцию при сворачивании UI и даёт отмену; после уничтожения процесса
экспорт не продолжается сам и готовые файлы остаются, перенос восстанавливается
по журналу. Смена аккаунта не публикует файл предыдущего аккаунта.
