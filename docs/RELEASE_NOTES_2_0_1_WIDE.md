# YMPlayer 2.0.1-build61

Утверждённый широкий логотип: монограмма YM + Player2. Arial Black с наклоном 7°, медный знак и белая или чёрная надпись по фону. Новая плитка Android TV использует эту же композицию.

Изменены только брендовые изображения. Компактный логотип, палитры и функции плеера сохранены. Проверены совпадение с утверждённым эскизом, пять плотностей TV banner, сборка/подпись и отображение на Android TV.

Пользовательские скины — следующий этап 2.1.0.
