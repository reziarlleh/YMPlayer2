## Проверено в текущих исходниках

PlayerApplication.restoreLaunch читает отдельный LaunchState. Музыка продолжается
при сохранённом playing=true; удалённый источник ждёт окончания LOADING аккаунта
и повторно проверяет профиль/сохранённое состояние. Повторный вызов в работающем
процессе не создаёт новый Play. Радио получает сохранённый playing отдельно.
AndroidPlayback.command сохраняет явное намерение до медленной команды;
checkpoint не выдаёт ошибку потока за ручную паузу, тихий reconnect защищён.
Четыре ранее исправленных механизма и их тесты остаются в коде.

Сравнение124→125: PlayerApplication, AndroidPlayback, LaunchStateStore и
AudioService побайтно одинаковы по Git blob.125 исправлял кэш и обложки,
не менял эту политику восстановления. Это проверка исходников, не воспроизведение
случая Fox_7. [Сравнение и границы](qa/startup-policy-2026-11-05/review.json).

Для расследования D-004 нужно различить сохранённую паузу и сорвавшуюся попытку
Play. Полезный диагностический след: сохранённый источник/намерение, решение
restore, готовность аккаунта/источника, фактическое состояние и причины Pause/Stop,
ошибки либо потери аудиофокуса. Обычный PLAYBACK_PAUSED сам по себе не указывает
причину. Дополнение такой диагностики здесь не реализовано.

## Предложение для отдельного решения

- **Авто — по умолчанию.** Восстановить прежний источник, позицию и намерение:
  играло — продолжить, была пауза — оставить паузу.
- **Плей.** Только явный выбор владельца настройки: один запрос продолжения
  сохранённого источника при новом запуске после готовности данных.
- **Пауза.** Восстановить выбранное и позицию без начала воспроизведения.

Это настройка политики, не эмуляция клика и не цикл Pause→Play. Её нельзя
повторно применять при каждом onResume, повороте или возврате из навигатора;
не следует перезапускать уже звучащий сервис. Пока запуск ожидает данные,
новая ручная Pause/Stop/смена источника должна отменять старое намерение.
Недоступная сеть/аккаунт/аудиофокус не обходятся принудительным повтором.
Точную область действия для музыки/радио/клипов ещё нужно согласовать.

Вариант записан как предложение, а не утверждённая реализация или новая версия.
