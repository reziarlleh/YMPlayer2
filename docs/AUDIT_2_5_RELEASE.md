# Аудит и выпуск 2.5.0 — текущая цель

Начато 7 октября 2026 по прямому запросу владельца. База: main / beta95,
source e07c179, итоговая документация09ee413. Владелец: «Всё круто», разрешён
стабильный выпуск после тщательного аудита. Это новое разрешение заменяет
прежнее ожидание отдельного разрешения на stable2.5; аппаратные результаты
и проверку личного POST по-прежнему описывать точно, без выдуманных подтверждений.

## Порядок выполнения

1. Сверить багрепорт, планы, RepoWise и фактические зависимости. Проверить
   заглушки, неиспользуемые функции/ресурсы, тестовые компоненты в release.
2. Проверить жизненный цикл/восстановление, профиль/авторизацию, конкурентные
   запросы/пагинацию, сеть, local/USB/offline, радио/музыку/клипы, updater.
   Для каждого удаления — вызовы/manifest/reflection/тесты; RepoWise — кандидат,
   а не доказательство. Не переделывать рабочую архитектуру ради оценок.
3. Исправить подтверждённые ошибки и B-006, добавить проверки поведения;
   сохранить исходные отказы и решения, исключить случайные изменения данных.
4. JVM, сборки debug/release и lint; подходящая регрессия на эмуляторах API28
   и TV29, signed upgrade beta95/old stable84, сохранение сеанса/профилей.
5. Выпустить подписанную стабильную2.5.0 с новым сквозным Build, четырьмя
   assets, latest/оба feeds/резервный APK. Сверить HTTP/SHA/подпись/GitHub.
6. Актуализировать статус/план/баги/карты/обе инструкции/README/историю и
   журналы; обновить нативную память отдельной ad_hoc note по запросу владельца.

## Находки и доказательства

На исходном срезе с новыми воспроизводящими тестами:32 core-сценария,
три отказа подтверждают две ошибки. B-015 — повторяющиеся страницы каталога/
избранного Радио с новым cursor не останавливают автопагинацию. B-016 —
карточка артиста отменяет незавершённый родительский запрос; Back восстанавливает
его пустую копию без перезапуска. Исправления подготовлены, первичный отказ
сохранён в QA; финальные проверки в работе.

B-006: новые отсутствующие artist/album/genre хранятся пустыми, подписи переводит
UI. Schema3→4 сохраняет имена и даты, только сбрасывает metadata-cache у возможных
старых заполнителей для чтения оригинальных тегов. Отсутствующий носитель/старые
архивные ссылки не позволяют доказать происхождение совпадающей русской строки:
её сохраняем дословно до успешного чтения, а не угадываем. JSON тоже сохраняет
значения и перечитывает только кандидатов. Есть тест реального WAV без тегов,
восьми языков/настоящих совпавших имён и schema3 с сохранением first-seen.

Удалён старый MessageScreen клипов и два его сообщения во всех пакетах;
fallback обложки переименован из DemoArtwork в FallbackArtwork, он нужен
при отсутствии картинки. DemoCatalog/контроллер используются в debug и тестах,
не удаляются как мусор; отсутствие в конечном APK проверяется по R8.
RepoWise:56 кандидатов, ни одного safe-to-delete. Gradle/scripts, extensions,
enum, callbacks и sizeOf — вызовы проверять вручную. Старые runtime-отчёты
не выдавать за новые прогоны. Приватные
диагностики/ключи, непубликовавшиеся APK88–91 и соответствующие исторические
свидетельства не удалять и не публиковать под видом очистки финального кода.

выявил B-017: нормализованный route после beta94 вычислен как обычный val;
если навигация и Back приходят до следующего Compose-кадра, handler использует
старый экран. Отказ NavigationTest строка39 сохранён. Добавлен детерминированный
сценарий sectionSwitchAndBackInSameFrameUseCurrentRoute; сначала прогон до правки,
затем исправление и новый сквозной кандидат.96 не переиспользовать/не публиковать.

и проверка строки библиотеки без прокрутки. Они не объявляются багами продукта.

Цель active; stable остаётся84 до завершения проверки. Границы SAF/SQLite,
OAuth/session, radio/catalog, wave/clip prefetch, skin parser и updater проверены
по RepoWise/context и исходникам. Выполняются JVM/debug APK/AndroidTest/lint;
затем полный доступный native-набор API28/TV29 и signed stable выпуск.
