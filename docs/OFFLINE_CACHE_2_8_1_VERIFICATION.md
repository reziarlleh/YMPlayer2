14–15 ноября 2026. База — принятый stable 2.8.0-build144. Подготовлен подписанный
**2.8.1-build145**, 4757699 bytes; [APK и приёмка](MANUAL_2_8_1_BUILD145.md).
Технические проверки завершены. Stable, Latest и update feeds остаются 144;
владелец новый кандидат ещё не принимал. [Согласованный план](PLAN_2_8_1.md),
[первоначальная спецификация](PORTABLE_OFFLINE_CACHE_DESIGN.md).

## Фактическое поведение кода

- Приватные привязки `offline-locations-v2` разделены по profileId + UID Яндекса.
  Старые `offline-location` используются только для миграции известных профилей
  и завершения прежней операции. Новые профили не наследуют старый общий USB.
- Самостоятельный корень получает `ymplayer2-cache.json`: applicationId, format=2,
  постоянный cacheId и accountUid. Токен, локальный UUID профиля и абсолютные
  пути к аудио туда не входят. Аудио, обложки и суммы остаются прежними файлами;
  локальный ускоряющий индекс перестраивается и не требуется для переноса.
- При обновлении известный v1-корень описывается на месте. При выключенном
  общем кэше запись паспорта/миграция ждут включения. Недоступный привязанный USB
  не подменяется внутренней папкой. Вход пользователя и глобальные параметры
  не меняются.
- Выбор пустой/обычной папки создаёт отдельную служебную подпапку только текущего
  владельца. Новый формат того же UID подключается с подтверждением и объединением.
  Целевые исправные файлы проверяются и повторно не скачиваются.
- Старый неизвестный кэш не содержит читаемого UID. Перед импортом запрашивается
  подтверждённый список лайков; совпадающие записи копируются в новый корень,
  оригинальный неизвестный набор остаётся. Без сети проверка не заменяется пустым
  списком. Разные UID, новый неподдерживаемый формат и занятый другим профилем
  корень отклоняются. В одной родительской папке разрешены разные корни.
- До полного чтения аудио проверяются объём и доступ; при копировании проверяются
  исходные суммы, размер и SHA-256 записанной копии. Исходное очищается только
  после фиксации привязки. Операция журналируется отдельно для каждого владельца.
  Незавершённый новый корень удаляется; после фиксации повторяется только очистка.
  Неизвестные файлы прежней папки и остальные профили не удаляются.
- Контроллер и FileTransferService проверяют ожидаемого владельца и глобальное
  включение. Смена профиля, отключение или отмена не могут поздно переключить
  чужую папку. Синхронизация приостановлена на время переноса. Просмотр найденного
  кэша без подтверждения сохраняет готовый список.
- Удаление профиля убирает его приватный кэш и привязки; пользовательский корень
  остаётся переносимым. Это исправление D-008. Удаление приложения выполняет
  Android: приватные файлы исчезают, обычные внешние документы остаются. После
  переустановки требуется снова войти и предоставить доступ к папке.

## Настройки

Шестерёнка: «О приложении» первым, качество звука, общие параметры кэша,
боковая панель, обновление предпоследним и диагностика последним.
Профили → «Настройки профиля»: язык, масштаб, скины/тема; у Яндекс-профиля —
папка, синхронизация, проверка и очистка его кэша. Назад из персонального
дочернего экрана возвращает в персональные настройки. Папки локальной музыки/USB
по прямому ответу владельца остаются общими и управляются в медиатеке.
Все новые сообщения и уточнение персонального языка представлены на восьми языках.

## Границы

SAF в этих проверках — независимый тестовый DocumentsProvider на эмуляторе,
не физическая USB-флешка владельца. Авторизация/лайки из изолированных тестов,
не личный аккаунт пользователя. Android сохраняет только общие документы,
не app-specific внешние каталоги; разрешение после удаления выдаётся заново.
Потеря USB/отзыв доступа обрабатываются как недоступность, сохранность данных
при аппаратном отказе носителя не обещается. Размеры/суммы проверяются при переносе;
обычная синхронизация по-прежнему не перечитывает всю тысячу аудиофайлов.
Старая версия приложения не обязана читать новый формат.

RepoWise context недоступен из-за `ModuleNotFoundError: tree_sitter`; проверены
сами исходники. Индекс не выдаётся за актуальный. Личная приёмка кандидата
владельцем и стабильная публикация не проводились.
