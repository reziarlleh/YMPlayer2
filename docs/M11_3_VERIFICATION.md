# M11.3 — адресный доступ коллекций к локальному индексу

Дата: 2026-09-28. Выпуск: `2.0.0beta-build45`.

## Реализовано

- `IndexedLocalLibrary.tracksByIds` читает метаданные указанных ID из SQLite
  безопасными пакетами по 400. Порядок плейлиста задают сохранённые ссылки,
  а не порядок ответа базы; неизвестные ID остаются в коллекции как
  недоступные ссылки.
- Создание плейлиста с треком, добавление трека и добавление в избранное
  запрашивают только нужный ID. Переименование, удаление, перестановка и
  снятие избранного не перечисляют каталог. Формат `user-collections.json`
  и сохранённые ID не меняются.
- Экран избранного и плейлиста разрешает только ID выбранной коллекции.
  Окно добавления ищет в SQLite и загружает по 80 строк за раз; убран
  прежний проход по всей локальной медиатеке при каждом вводе символа.
- У дисковых страниц снят искусственный общий предел в 50 000 позиций;
  один SQL-запрос остаётся ограниченным.

## Граница этапа

Плеер по-прежнему использует полный снимок локальной библиотеки и при
автоматическом следовании за ней может создавать очередь из всего каталога.
Это требует отдельного изменения правил выборки и проверки восстановления
очереди, MediaBrowser, USB и профилей. Объединение с каталогом Яндекса также
остаётся в M11. Аппаратная приёмка K4811 не блокирует эти работы.
