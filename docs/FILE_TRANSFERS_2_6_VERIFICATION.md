# Перенос кэша и экспорт MP3 — проверка 2.6

В работе13 октября2026; опубликована2.5.5-build104. Это промежуточная запись,
не свидетельство уже опубликованного2.6. [Текущий план](PLAN_2_6.md).

## Реализация

CacheLocationAccess/AudioExportAccess в core; File/SAF адаптер и экспортёр
в library/offline; окна в feature/shell; пикеры и foreground dataSync в app.
Постоянная синхронизация по-прежнему только «Мне нравится».
Эксперимент приборки и его beta не изменяются.

Перенос сохраняет account-scoped формат v1/SHA256 имена, все профили,
аудио/обложки/JSON/контрольные суммы. Проверяются размер и SHA256 каждого файла.
Свободное место проверяется до копирования и во время записи, запас32/16MiB;
неизвестная ёмкость — отказ. Уникальная папка YMPlayer2-offline-UUID принадлежит
приложению; выбранная родительская папка и чужие файлы не удаляются.
Preferences переключаются после проверки копии. Журнал pending/previous
позволяет убрать незавершённую копию или прежний корень после перезапуска.
После commit очистка не прерывается отменой. SAF backup публикации
восстанавливается при следующем чтении. Нельзя переносить внутрь текущего корня.

Синхронизация и перенос используют общий location lease, а короткое чтение/
публикация защищены отдельным Mutex. Сетевой запрос синхронизации не блокирует
выбор уже скачанного трека. При самом переносе следующий файл ожидает его окончания. Непрерывная
очередь во время длительного переноса не обещается. Возврат во внутреннюю
память выполняется тем же проверяемым переносом.

Плейлист/альбом читается по всем страницам с сохранением порядка/повторений.
Офлайн использует проверенный файл своего аккаунта; иначе полный HIGH источник.
Сетевой источник скачивается во временный файл выбранной папки с таймаутами
и лимитом128MiB, без внутреннего staging. MP3 копируется пакетами; другие
MediaCodec форматы декодируются и кодируются Jump3r/LAME в CBR320/44.1kHz.
ID3v2.3 содержит title/artist/album/track. Защищённый поток не экспортируется.
Публикация после проверки MP3 и полной длительности. Отмена убирает текущие
временные файлы, оставляя завершённые MP3. Ошибки отдельных треков считаются.
Смена аккаунта запрещает публикацию результата старого аккаунта.
Перенос и экспорт взаимоисключаются.

Шаблон сохраняется: {number}/{artist}/{title}/{album}/{id}, однократная
подстановка, предпросмотр и (?) справка. Автоматический .mp3, замена запрещённых
символов, UTF8 основание180байт, защита DOS имён, совпадения(2),(3) без перезаписи.
46 новых сообщений:724 всего/8 языков. [Лицензия и исходники](THIRD_PARTY.md).

Media3 idle-notification AFTER_STOP_OR_ERROR заменена на NEVER. Системный
deleteIntent передаёт COMMAND_STOP по официальным исходникам1.11.0.
SystemBrowserTest проверяет удаление карточки, повторный запуск и browser.stop.
Кнопки клипов ⏮/⏭ обозначают переключение, не перемотку.

## Промежуточные проверки и отказы

- Компиляция storage/encoder/UI debug прошла; добавлены JVM filename tests.
- Первый TV29:6/10 native,4 отказа. STOP и прежние browser сценарии прошли.

  DocumentsProvider команды в super; фикстура исправлена.

  выдавал PatternSyntaxException. Скобка экранирована; требуется native повтор.

  также перегружали16GB RAM. Проверки по одному AVD, --max-workers=2.
- Логи .local-build/transfers-qa и transfers-*.txt; финальные компактные
  свидетельства будут включены в docs/qa после успешного повторного прохода.
- Повтор TV29:33/33; API28:33/33 плюс настоящий foreground-сервис1/1.
  API35 первый расширенный проход36/36. Повтор после MIME коррекции35/36:
  один отказ на начальном внутреннем Play без Activity, до отправки STOP;
  отдельный сценарий1/1 и вся SystemBrowser группа6/6 затем прошли.

  Это не объявляется доказательством причины первоначального отказа.

  Native MP3 packet-copy сохраняет все пакеты; AAC экспорт полностью
  декодируется с ненулевым звуковым сигналом. Android regex native повтор прошёл.
- Зафиксирован SurfaceFlinger/ubsan у TV29 при стандартном новом Dialog:
  без app fatal, instrumentation прервана. Перешли на стабильное полноэкранное
  platform-окно с ограниченной карточкой, как AboutDialog. Последующие33/33 прошли.
- [AOSP FileUtils](https://android.googlesource.com/platform/frameworks/base/+/android10-release/core/java/android/os/FileUtils.java)
  корректирует расширение при несовпадении MIME. JSON создаётся application/json,
  MP3 temp — audio/mpeg; запрашиваемое имя проверяется. Fixture моделирует
  несовпадение вместо всегда успешного создания произвольного имени.
- Финальная сверка обнаружила длительный read-lock на network sync. Разделён
  location lease и read/write lock; добавлен тест зависшего resolve с чтением
  другого готового трека. Этот новый проход ещё требуется.
