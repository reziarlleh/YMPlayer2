# YMPlayer2 2.8.0 — полный состав цикла

Кандидат **2.8.0-build141**,14 ноября2026. Публикация ещё не разрешена;
ниже состав версии для проверки, а не объявление состоявшегося релиза.

- Пользовательские профили вместо фиксированных Основной/В дороге/Гость:
  отдельные аккаунты членов семьи или водителей общего автомобиля.
- На чистой установке один встроенный **Локальный**, для музыки устройства/USB.
  Он не удаляется и не переименовывается. **Добавить профиль Яндекс** открывает
  отдельный вход; имя профиля автоматически берётся из аккаунта. Через меню
  Яндекс-профиля можно задать своё имя или удалить его с подтверждением.
- Из Локального функции с аккаунтом сначала предлагают выбор Яндекс-профиля.
  Если их нет, приложение предлагает подключить аккаунт. Без подтверждения
  профиль не создаётся и авторизация не начинается; отмена сохраняет экран/сеанс.
- Свои аккаунты Яндекса, избранное, локальные плейлисты, история и очереди.
  Локальные файлы доступны во всех профилях; авторизация — в отдельных Яндекс-профилях.
- Свои язык, тема, скин и масштаб. Общие папки, разрешения Android,
  установленный набор скинов, качество звука и размещение кэша остаются общими.
- После выбора другого пользователя плеер открывается на паузе с его треком,
  очередью и позицией. Запоздалые запросы прежнего пользователя не вмешиваются.
- Прежние аккаунты и данные переносятся без повторного входа из-за смены
  названия профиля. Прежние ID/сессии/очереди/оформление сохраняются, Локальный
  добавляется отдельно. Полученные имена и пользовательские подписи не переводятся.
- Новые тексты переведены на все восемь языков; поддержка Android6+,
  приложение/подпись/данные и стабильный канал сохранены.

- Расширен экспорт диагностики: фактические команды Play/Pause/Stop, доступный
  источник Android и моменты ухода окна в фон/возврата. Запись не меняет
  приоритет Pause/Stop и не включает принудительное воспроизведение.
