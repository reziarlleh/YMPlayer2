# M8.4 — восстановление после загрузки и физическая приёмка

Дата: 2026-09-25. Этап **частично проверен**, физическая часть открыта.

Добавлен повторяемый двухфазный сценарий `BootCheckpointTest` и
`tools/check-boot-recovery.ps1`. Первая фаза записывает локальную очередь
профиля `road`, текущий трек и позицию после паузы. Скрипт перезагружает
именованный эмулятор; в новом процессе приложения вторая фаза проверяет
профиль, очередь, трек, позицию и то, что музыка сама не заиграла.
Скрипт явно принимает только `emulator-N` и не устанавливает APK на
физическое устройство.

Проверено на Android 15 phone и Android TV API 29: обе фазы прошли после
полной перезагрузки каждого эмулятора (`OK (1 test)` для seed и verify).
Фикстура SAF повторно доступна после boot. Это проверка восстановления
локального checkpoint, а не подтверждение CWG, K4811, физических кнопок,
реального USB и HyperOS. Устройство владельца по ADB в этой сессии не видно.

До закрытия M8.4 нужно отдельно проверить на целевом устройстве:
аппаратные Play/Pause/Next при остановленной службе и после boot, браузер CWG,
возврат аудиофокуса, сохранение очереди после перезагрузки и USB hot-plug.
На момент этой проверки текущим релизом оставался build24; тестовый debug APK
не был новым beta-релизом. Актуальный номер указан в
[PROJECT_STATUS.md](PROJECT_STATUS.md).
