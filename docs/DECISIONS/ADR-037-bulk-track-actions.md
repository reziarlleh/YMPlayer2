# ADR-037 — массовые действия над выбранными треками

2026-10-03. База — stable2.3.1-build76; [план](../PLAN_2_3.md).

Выбор хранится только в композиции текущего раздела, отдельным упорядоченным
списком явно отмеченных треков. Подгрузка следующей страницы не заменяет этот
список; смена профиля, источника/фильтра, категории, поиска, маршрута или Cancel
сбрасывает его. Режим не является новой постоянной очередью или копией каталога.
На карточке появляется checkbox; нажатие карточки выбирает, а не запускает трек.
Имена артистов в этом режиме не перехватывают нажатие. Обычный режим не меняется.

Одна общая панель для каталога/поиска, истории, недавно добавленного, локальных
плейлистов/избранного и онлайн-списков. В длинных каталогах/онлайн-выдаче она
находится над прокручиваемым списком только в режиме выбора. Enter/DPAD_CENTER переключают отметку; Back сначала
заканчивает выбор, затем поднимает на уровень выше. Недоступную локальную ссылку
можно включить в плейлист, но в очередь добавляются только доступные треки.

CollectionEdit.AddMany/CreateMany проверяют все локальные ID, удаляют дубликаты
с сохранением порядка и делают один AtomicFile commit до обновления state.
Отказ любого ID не оставляет половины изменения. Сохранённые ссылки не содержат
аудио URI; Яндекс-музыка не превращается в локальный плейлист. Cloud-редактор
остаётся существующим отдельным инструментом, массовая запись серверного плейлиста
не обещана этим выпуском.

PlaybackController.enqueueMany используется одной дисковой командой AndroidPlayback,
проверяет действующий каталог/профиль и один раз изменяет список ссылок. Уже
имеющиеся ID не добавляются повторно. Размер окна Media3 и алгоритмы волны не
меняются; это явное действие над обычной очередью с прежней семантикой enqueue.
История перед командой восстанавливает только метаданные выбранных онлайн-треков;
аудио по-прежнему получает текущий аккаунт. Новые пять сообщений переведены сразу
на все восемь языков.
