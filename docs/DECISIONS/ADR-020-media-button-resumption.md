# ADR-020: медиакнопки и возобновление системной сессии

Дата: 2026-09-24. Этап M8.2, функция F20.

В 1.x `YmpMediaButtonReceiver` принимает Play/Pause/Next/Previous/Stop и запускает
`YmpPlaybackService` соответствующей командой. Это даёт управление после остановки
службы, но привязано к старой реализации сервиса. В 2.x сохраняем поведение,
используя штатный `MediaButtonReceiver` Media3 и одну `MediaLibrarySession`.

Для запуска после остановки службы манифест объявляет receiver. Колбэк
`onPlaybackResumption` возвращает метаданные текущего элемента из checkpoint
активного профиля. Он только читает их: загрузка каталога и проверка доступности
URI выполняются обычным восстановлением `AndroidPlayback`. Внешние клиенты не
могут выбрать служебный ID возобновления через браузер. Если checkpoint не
содержит элемента или волны, колбэк возвращает пустой список. Запрос метаданных
при загрузке системы сам не запускает звук.

Когда служба уже работает, Media3 передаёт медиакнопки существующему транспорту.
`ExoPlayer.setAudioAttributes(..., true)` управляет аудиофокусом; собственный
параллельный запрос фокуса не нужен. Состояние интерфейса учитывает
`playbackSuppressionReason`: временно подавленное аудио не показывается играющим.

Проверки: [M8.2](../M8_2_VERIFICATION.md). Сценарии реальных кнопок, CWG и
перезагрузки на целевом устройстве остаются отдельной аппаратной приёмкой.
