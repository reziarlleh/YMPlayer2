# ADR-025 — внешний вид и команды SideBar для K4811

Дата: 2026-09-27. Уточнение владельца к M10: SideBar предназначен для его
магнитолы K4811; универсальная поддержка других аппаратных платформ не нужна.

Свернутая зона жеста не рисуется. Настоящее сенсорное окно остаётся узким,
как в [ADR-024](ADR-024-sidebar-edge-input.md); тап внутри него по-прежнему
принадлежит SideBar. Развёрнутая панель имеет только внешнюю трапециевидную
границу с широким основанием у края, белый контур и полупрозрачный тёмный фон.
Кнопки внутри — обычные круглые, с белыми значками и контуром. Для полного
набора команд сетка переносится на две колонки в низком альбомном окне и на
две строки у нижнего края.

Настраиваются семь команд: громкость +/−, mute, Play/Pause, Home, меню и Back.
«Спрятать сайдбар» всегда последняя и не отключается. Пустой набор команд
атомарно выключает SideBar и удаляет его окна; повторное включение требует
сначала выбрать команду. Старые сохранённые наборы остаются как были, а у
установок без настройки кнопок исходными остаются четыре кнопки M10.1.

Команды K4811 сверены с исходниками штатной панели из предоставленной
прошивки и диагностическим снимком владельца. В
`com.android.launcher`/`com.visualframe.SendKeyUtil` найдены broadcast
`com.nwd.action.ACTION_KEY_VALUE`, byte-extra `extra_key_value` и значения:
volume up 14, volume down 15, mute 2, Home 20, Back 18. Штатный лаунчер
открывает сетку приложений по
`com.nwd.action.suspension.DISPLAY_GRIDVIEW` с package `com.android.launcher`;
это и есть назначение кнопки «Меню», а не универсальная клавиша MENU.
Диагностический снимок K4811 содержит `ro.build.display.id`, начинающийся
с `K4811_`; adapter отправляет команды только при таком `Build.DISPLAY`.
Play/Pause отправляет обычное парное событие `KEYCODE_MEDIA_PLAY_PAUSE` через
`AudioManager` активной медиасессии. AccessibilityService, root и скрытые
системные API для этих кнопок не используются.

`sendBroadcast` подтверждает только отправку запроса, не действие на устройстве.
Эмулятор проверяет окно и настройки, но не принимает NWD-команды. Реальная
реакция K4811, Play/Pause на разных активных плеерах и «Меню» при нестандартном
лаунчере остаются физической приёмкой. Подтверждённый в 1.x протокол reboot
отдельный; он не включён в эти семь кнопок и не меняется этим решением.

[Проверки M10.3](../M10_3_VERIFICATION.md).

Дополнение [ADR-026](ADR-026-k4811-sidebar-sleep-reboot.md) расширяет состав
кнопок до девяти в build38. Семь кнопок выше — историческое состояние build37.
