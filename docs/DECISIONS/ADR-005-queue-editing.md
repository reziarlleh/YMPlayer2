# ADR-005 — режимы воспроизведения и редактируемая очередь

2026-09-09. Первый функциональный прирост M3.

Повтор и перемешивание принадлежат аудиодвижку. `PlaybackController` предоставляет
режимы OFF/ALL/ONE и независимый shuffle; UI только отображает состояние и передаёт
команды. Ручное «Далее» переходит к следующему треку даже при повторе одного.

Очередь хранит уникальные идентификаторы доступных треков. Добавление не запускает
аудио. Перестановка и удаление другого трека используют операции плейлиста Media3,
чтобы сохранить текущий поток и позицию. Удаление текущего трека предварительно
ставит плеер на паузу; очистка тоже останавливает воспроизведение. Музыкальные
файлы и индекс каталога эти команды не изменяют.

Начальная очередь следует выбранному источнику и обновляется после сканирования.
После ручного изменения она сохраняет пользовательский состав и порядок.
Пустая очередь, полученная очисткой, остаётся пустой после rescan и перезапуска.
Выбор источника снова строит очередь по источнику. Запуск трека, которого нет
в ручной очереди, строит очередь из доступной коллекции и снимает фильтр источника.

Очередь, позиция, повтор и признак shuffle сохраняются отдельно для профиля.
После восстановления и переключения профиля плеер остаётся на паузе.
При shuffle экран показывает базовый редактируемый порядок и предупреждает о
случайном воспроизведении. Конкретная случайная перестановка после нового запуска
не сохраняется; её создаёт Media3. Это не история прослушивания и не плейлист.

Устойчивое восстановление ручной очереди после полного исчезновения USB относится
к следующей части M3. Сейчас недоступные треки исключаются из активной очереди;
оригиналы и последние записи каталога сохраняются согласно правилам M2.

Основание поведения native playlist:
[Media3 playlists](https://developer.android.com/media/media3/exoplayer/playlists).
Пользовательские плейлисты, избранное и обложки — следующая часть M3.
