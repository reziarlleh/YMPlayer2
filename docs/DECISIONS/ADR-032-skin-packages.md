# ADR-032 — скины как проверяемые визуальные данные

Дата: 2026-10-01. Статус: принято для M13 / 2.1.0.

Встроенный AppSkin уже отделяет оформление от поведения, но требует пересборки.
Для пользовательского оформления вводится ZIP `.ymskin` с версионированным
JSON-контрактом: [формат](../SKIN_FORMAT.md). Парсер и хранилище находятся в
существующем designsystem; нового слоя playback или provider не требуется.

Вектор использует ограниченный список SVG path data в JSON. Compose PathParser
строит ImageVector; tint, команды, подписи, геометрия и hit targets задаются UI.
Это позволяет редактировать изображения и цвета без исполнения кода пакета,
сетевых запросов или замены маршрутов. Шрифты и размеры в контракт v1 не входят:
сохранение композиции плеера и крупного текста важнее произвольной вёрстки.

Архив читается с пределами размеров и проверкой путей без распаковки. Preview
не активирует пакет; применение сохраняет проверенную копию атомарно. Неудачный
импорт не меняет текущий скин; повреждение активной копии при запуске возвращает
встроенный «Оксид». Пакеты независимы от профилей и данных авторизации.

Compose получает AppSkin из StateFlow, native-панель клипов обновляет только
цвета существующих Views. Плееры, очереди и сессии не пересоздаются. Белый
K4811 SideBar и системные брендовые ресурсы сохраняют отдельные контракты.
