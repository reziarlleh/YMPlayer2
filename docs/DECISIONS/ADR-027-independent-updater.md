# ADR-027 — самостоятельные обновления YMPlayer 2

Дата: 2026-09-28. Область: M12/F24.

## Решение

2.x использует собственные пакет, подпись, манифест, настройки и папку APK.
Рабочая схема 1.x служит поведенческим эталоном: сначала HTTPS-манифест GitHub,
при ошибке — jsDelivr; затем проверка размера и SHA-256 каждого кандидата APK,
автоматический переход ко второму адресу при ошибке, системное разрешение на
установку и системный установщик. Код 1.x и его хранилище не используются.

Модуль `updater/android` отвечает за сеть, ограничение размера, проверку
пакета/сквозного Build/подписи установленного приложения и передачу APK через
FileProvider. `app/UpdateCoordinator` владеет состоянием проверки, суточным
интервалом автопроверки и ожидающей установкой. `feature/shell` видит только
`UpdateAccess`; настройки и предложение новой версии не вызывают сетевой код.

Манифест `update/manifest.json` обслуживает текущие beta-сборки. При первом
stable выпуске появляется `update/stable.json`, который получает только stable;
beta может перейти на stable. Решение о новизне принимает `versionCode`, а не
лексикографическое сравнение `versionName`. 2.x никогда не принимает манифест
пакета 1.x или иной канал для stable-приложения.

APK каждого выпуска хранится также в Git-снимке его тега, чтобы jsDelivr мог
выдать именно этот файл по неизменяемому адресу. В `main` находятся актуальный
манифест и последний APK; старые APK остаются доступны через теги выпусков.
Скрипт подготовки проверяет SHA-256 и лимит 20 МБ на файл
для CDN. При превышении лимита выпуск блокируется до выбора другого зеркала.
Манифест jsDelivr по `@main` кешируется как ветка и может запаздывать после
выпуска: это резервная доступность, а не немедленная синхронизация. Версионный
адрес APK остаётся неизменяемым. Задержка наблюдалась при выпуске build41–42
и отражена в [M12.2](../M12_2_VERIFICATION.md).

Автопроверка запускается при открытии приложения не чаще раза в сутки по
умолчанию и выключается в настройках. При новой версии пользователь выбирает
загрузку; после проверки файла Android запрашивает разрешение/подтверждение
установки. Тихая установка обычному приложению недоступна. Ошибка фоновой
проверки не мешает запуску плеера; ручная проверка показывает ошибку.

## Основания и границы проверки

- 1.x: `AppUpdateManager`, `YmpSettings.shouldAutoCheckUpdates` и
  `update/manifest.json` в отдельном репозитории; поведение проверено в нём.
- [Android PackageManager](https://developer.android.com/reference/android/content/pm/PackageManager)
  предоставляет данные пакета и подписей APK; окончательную совместимость
  подписи устанавливает системный установщик.
- [Android FileProvider](https://developer.android.com/training/secure-file-sharing)
  передаёт установщику временный `content://` доступ к APK.
- [jsDelivr](https://github.com/jsdelivr/jsdelivr) объявляет ограничение 20 МБ
  на один файл GitHub. Доступность конкретного URL 2.x проверяется при выпуске.

Эмулятор и проверки сетевых источников не доказывают доступность CDN из всех
сетей России и автоматическую установку без участия пользователя.
