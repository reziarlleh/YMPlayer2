# ADR-024 — форма SideBar и границы перехвата касаний

Дата: 2026-09-27. M10.2/F21–F22.

У M10.1 невидимые окна захвата занимали 28 dp вдоль боков и 28 dp снизу на
60% длины края. Даже если рисовать лишь тонкую линию, всё прямоугольное окно
получает начальное касание. Поэтому касания на чужих элементах у края,
включая клавиатуру, могли пропадать.

Встроенный PRISM SideBar теперь рисуется отдельным `SideBarAppearance`:
основная панель и кнопки имеют угловатую форму трапеции, широкая сторона
примыкает к выбранному краю экрана. Палитра и геометрия не связаны с командами
панели. Это встроенное оформление; импорт пользовательских скинов остаётся M13.

Свёрнутые маркеры одновременно являются настоящими сенсорными окнами:
боковые — 8×112 dp, нижний — 28% ширины экрана × 8 dp. Открывает панель
направленный свайп к центру от маркера длиной более 24 dp. Касания **вне**
маркеров получает приложение под ними; касание **внутри** маркера принадлежит
SideBar. Передавать уже полученный `ACTION_DOWN` чужому приложению надёжно и
безопасно нельзя. `FLAG_NOT_TOUCH_MODAL` пропускает касания только вне границ
окна; прозрачная картинка сама по себе не делает прямоугольное окно прозрачным
для касаний. [Правила окон Android](https://developer.android.com/reference/android/view/WindowManager.LayoutParams)
и [ограничения сквозных касаний Android 12+](https://developer.android.com/about/versions/12/behavior-changes-all)
не позволяют обещать полную передачу касаний через touchable overlay.

Окна SideBar используют `FLAG_NOT_FOCUSABLE | FLAG_ALT_FOCUSABLE_IM`: при
открытой клавиатуре они оказываются ниже окна IME, в том числе нижний маркер.
Это дополняет сокращение зон и не требует AccessibilityService или
пересылки синтетических касаний в другие приложения. При повороте служба
пересоздаёт маркеры, иначе нижнее окно сохраняло бы прежнюю ширину и вновь
захватывало лишние касания. Реальное поведение
HyperOS, жестовой навигации и автомобильного экрана требует проверки владельцем.

[Проверки M10.2](../M10_2_VERIFICATION.md).

Уточнение владельца и новое оформление зафиксированы в
[ADR-025](ADR-025-k4811-sidebar-controls.md): с M10.3 маркер невидим,
трапеция остаётся только внешней границей панели, кнопки стали круглыми.
[M10.5/build43](../M10_5_VERIFICATION.md) задаёт срезы внешнего контура
под 45° и больший зазор вокруг кнопок, не меняя окна захвата жеста.
