# ADR-036 — первое появление локальной музыки

2026-10-03. [План 2.3](../PLAN_2_3.md), следующий шаг после истории.

Время добавления принадлежит каталогу, а не файлу: modifiedMillis отражает
изменение файла/тегов и для этой задачи непригоден. В SQLite local-catalog.db
schema3 добавлено added_at и индекс порядка. При транзакционной замене одной
папки сохраняются прежние даты её ID; только новые ID получают время сканирования.
Ни аудиофайл, ни URI, ни алгоритм воспроизведения не меняются.

Миграция schema1/2 и импорт legacy JSON дают старым строкам нулевую неизвестную
дату. Они остаются в обычном каталоге и не попадают в новый список. Повторный
scan сохраняет ноль. Отключение USB лишь помечает строки недоступными и сохраняет
даты; забытая папка или удалённый из каталога файл после повторного добавления
считаются новым появлением. Общий local/USB каталог доступен всем профилям;
очередь и действия продолжают принадлежать выбранному профилю.

Экран запрашивает страницы по80 через IndexedLocalLibrary; следующие страницы
добавляются без перечитывания уже загруженных. Изменение ревизии сбрасывает
страничный кэш. Никакой отдельной огромной очереди не создаётся: нажатие трека
запускает существующий механизм списка из одного ID, кнопка очереди добавляет ID.
Все восемь языков обновлены одновременно. История и новый раздел — один ряд
кнопок в медиатеке, с обычной навигацией вверх/выбором источника через ChoiceRow.

Проверки и публикация: [2.3.1 verification](../RELEASE_2_3_1_VERIFICATION.md).
