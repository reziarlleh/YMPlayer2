# ADR-026 — сон и подтверждаемая перезагрузка SideBar K4811

Дата: 2026-09-27. Владелец напомнил о двух работавших в 1.x кнопках и подтвердил
их действие на своей K4811. Они входят в SideBar 2.x как отдельные переключатели,
после Back и непосредственно перед обязательной кнопкой «Спрятать сайдбар».
При существующей установке их выбор по умолчанию не включается.

**Сон:** `Ts18AudioControls.sleep()` в 1.x посылает
`com.nwd.action.ACTION_KEY_VALUE` с byte-extra `extra_key_value=0`, после чего
SideBar сворачивается. Несмотря на историческое имя класса, тот же код 0
найден в `SendKeyUtil.sendPowerEvent()` и штатной панели предоставленной K4811.
В 2.x команда изолирована в `K4811Controls`, ограничена `Build.DISPLAY=K4811*`
и использует foreground broadcast, как рабочий путь 1.x.

**Перезагрузка:** кнопка 1.x не перезагружает немедленно. Она открывает
`HeadUnitRebootActivity`, подключается к экспортированной SettingService,
проверяет descriptor `com.nwd.setting.service.SettingFeature` и включает
подтверждение только после подключения. После согласия фоновый поток делает
ровно один `transact(0x1c)` с `writeByte(2)`, читает ответ и не повторяет запрос
при неизвестном результате. Типы сброса не принимаются от вызывающего кода.
В 2.x те же границы находятся внутри `headunit:sidebar` —
`K4811RebootActivity` и `K4811RebootProtocol`; окно закрывается без отправки
при отмене или уходе пользователя. Код 1.x не изменялся.

Владелец подтвердил фактическую работу обеих команд в 1.x. Тесты 2.x с
подставным Binder проверяют именно reboot-only type 2, отмену и отказ службы;
они не перезагружают устройство. Успешность переноса на K4811 проверяется
владельцем отдельно. [Проверка M10.4](../M10_4_VERIFICATION.md).
