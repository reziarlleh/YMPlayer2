# ADR-028 — дисковый индекс локальных метаданных

Дата: 2026-09-28. Область: M11/F16.

## Решение

`library/local` хранит корни SAF и метаданные треков в приватной SQLite-базе
`local-catalog.db`. Первое открытие переносит прежний `local-library.json` в
одной транзакции; флаг завершения записывается в той же транзакции. После этого
JSON остаётся историческим резервом, но не читается и не обновляется: старый
файл не может воскресить удалённую папку. Идентификаторы, URI документа,
размер, время изменения и имя обложки сохраняются. Аудио не копируется.

Обход каждого SAF-корня либо даёт полный новый набор метаданных, либо сохраняет
последний набор этого корня с `available=false`. Замена набора всех корней
атомарна. После старта доступность также сбрасывается до повторного обхода.
Устройство/USB показываются через запросы к базе по 80 строк с устойчивым
порядком `title_key,id`; группы считают строки в базе и получают один образец.
Фильтры, поиск и сортировка выполняются в запросах, а экран загружает следующую
порцию только по команде пользователя.

На этом этапе `LocalLibrary.state.tracks` всё ещё держит полный снимок для
очереди, плейлистов и восстановления воспроизведения. Его удаление требует
отдельного перевода этих потребителей на выборку по ID и проверки регрессий.
Яндекс-страницы пока остаются отдельным источником; объединение источников —
следующая часть M11.

## Почему

Запросы M11.1 ограничивали список на экране, но каждый раз проходили по всему
снимку в памяти, а JSON перезаписывался целиком. Дисковый контракт даёт
устойчивую постраничную выдачу и безопасный путь миграции, не меняя
идентификаторы треков и проверенную логику плеера за один шаг.
