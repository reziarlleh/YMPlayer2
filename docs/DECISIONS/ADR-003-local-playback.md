# ADR-003 — локальный каталог и настоящее воспроизведение

2026-09-09. M2 продолжает проверенный интерфейс M1 по запросу владельца.

Первый функциональный сценарий: пользователь выбирает папку через системный
Storage Access Framework, видит индекс аудиофайлов и воспроизводит их через
Media3. Приложение хранит метаданные и разрешение чтения; оригиналы не копируются
и не изменяются. Источник «Устройство» или «USB» выбирается при добавлении.

Физические модули `library:local` и `playback:android` вводятся под этот сценарий.
Контракты и модели остаются в Android-независимом core. Небольшой индекс хранится
атомарным JSON в приватной папке; обход и чтение тегов выполняются вне UI-потока.
Недоступная папка сохраняет прежние записи с отметкой недоступности. Отмена или
ошибка обхода не считается достоверным пустым каталогом.

MediaSessionService владеет ExoPlayer. Общий контроллер процесса передаёт команды
экрана сервису, а MediaSession обслуживает системное управление и уведомление.
UI не создаёт второй плеер. Профили используют общий локальный каталог и отдельные
постоянные очереди/позиции; смена профиля и восстановление процесса оставляют паузу.
Демонстрационный каталог используется только явным тестовым экраном debug.

M2 не включает Яндекс, облачные аккаунты, клипы, кэш аудио, SideBar или обновлятор.
Проверка эмулятора и проверка физического ГУ учитываются отдельно. Версия остаётся
beta; следующая выдаваемая сборка получает сквозной Build после build1.
