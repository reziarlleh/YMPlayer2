# ADR-029 — checkpoint автоматически следующей за библиотекой очереди

Дата: 2026-09-28. Область: M11/F05/F06/F16.

## Решение

Автоматическая локальная очередь определяется актуальным индексом библиотеки,
поэтому её полный список ID и метаданных больше не дублируется в checkpoint.
Сохраняются ID и позиция текущего трека, режим очереди и одна строка метаданных
для MediaBrowser до загрузки индекса. При восстановлении службы список вновь
строится в прежнем порядке из библиотеки; проигрывание остаётся на паузе.
Существующие полные checkpoints читаются, после чего следующая запись переводит
их в компактную форму.

Ручная очередь и волна определяются действиями пользователя и ответами сервера:
их порядок нельзя вывести из локального индекса. Их ссылки и метаданные
сохраняются по прежнему контракту, в том числе для недоступного USB.

Плеер больше не хранит параллельную карту всех треков. Для ручной очереди
разрешаются только её ID, а выбор уже присутствующего трека использует
саму очередь. Это отдельный шаг от будущего ограничения размера работающей
автоматической очереди: она пока содержит весь локальный каталог. Будущее
порционное представление должно отдельно сохранить переходы, shuffle/repeat,
системный браузер и восстановление позиции.

## Проверка

[M11.4](../M11_4_VERIFICATION.md) фиксирует тесты перезапуска службы,
порядка/позиции и регрессию после перезагрузки эмулятора. Полная очередь
большого каталога и K4811 остаются открытыми проверками.
