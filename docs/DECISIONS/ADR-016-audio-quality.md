# ADR-016: отдельное качество потока и постоянного кэша

Дата: 2026-09-20. M7.2 / F09 после build16.

## Рабочая логика 1.x

Reference: `D:/_codex/YaPlay`, commit `7d118b4e3ec817b706748ae8d129fdc00f3a0146`.
Проверены CHANGELOG 0.3.7/0.4.0, `AudioQuality`, `YmpSettings`,
`YandexMusicClient.chooseDownloadInfo/getDirectUrl`, `YandexTrackCache.ensureCached`
и отдельные пути постоянной загрузки / временной подготовки аудио.

| Вход | Поведение 1.x | Перенос в 2.x |
| --- | --- | --- |
| Отсутствующая/неизвестная настройка | AUTO | `AudioQuality.fromKey`, независимые стабильные строковые ключи; без миграции данных 1.x |
| Economy / Standard / High | Целевые 128 / 192 / 320 кбит/с | Максимальный доступный битрейт до цели; при отсутствии — ближайший выше |
| Auto / Maximum | Наибольший доступный битрейт | Оба режима сохранены, равнозначность объяснена на экране; это не обещание lossless |
| Несколько вариантов API | Не брать preview; небольшой бонус MP3, другие кодеки допустимы | Прежняя формула ранжирования; XML-подпись и проверка URL из M5.1 сохранены |
| Обычный поток / предзагрузка волны | stream_quality | `AndroidPlayback` передаёт снимок выбранного качества в каждый новый запрос; готовый буфер не сбрасывается |
| «Мне нравится» офлайн | cache_quality | `OfflineMusic` передаёт снимок настройки для следующего скачиваемого трека; исправные файлы повторно не скачиваются |
| Изменить настройку | Сохранить предпочтение, использовать при новых загрузках | Текущий трек/запрос не перезапускается; ни преобразования файлов, ни автоматической очистки |

Исходная формула выбора сохранена, арифметика выполнена в Long, чтобы битрейт
из ответа не переполнял Int. Новых фильтров кодека или обязательных полей нет.
Фикстуры проверяют выбор; успешный публичный preview не выдаётся за проверку
всех битрейтов личного подписочного аккаунта.

## Границы и интерфейс

`core/AudioQualityPreferences` хранит только два наблюдаемых значения и callback
сохранения. Оно не получает плеер, аккаунт или файловый кэш. `app` сохраняет
строковые ключи в собственных preferences 2.x и связывает зависимости.
Настройки общие для устройства, как в 1.x; токены и кэш по-прежнему изолированы.

`Настройки → Качество звука`: отдельные кнопки потока и офлайн-кэша открывают
список с текущим выбором. Экран и диалог допускают прокрутку, используют
дизайн-систему PRISM, семантику radio и видимый фокус. «Назад» возвращает
на уровень настроек. Компоновка главного плеера не меняется.

Для перевыгрузки существующей офлайн-коллекции в новом качестве пользователь
может удалить её файлы в «Офлайн» и запустить синхронизацию. Лайки при очистке
сохраняются. Обычная синхронизация ремонтирует недостающее, не обновляет
качество исправных файлов сама по себе.
