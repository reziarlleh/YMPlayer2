# ADR-002 — нативный M1 с явными демоадаптерами

Дата: 2026-09-09. Статус: реализовано и проверено в M1; см. [отчёт](../M1_VERIFICATION.md).

Владелец выбрал вариант A: плеер на главной, отдельная медиатека, постоянный
мини-плеер. Вместо переноса Activity/repository 1.x создан новый Kotlin/Compose
проект с четырьмя физическими модулями; будущие модули не создаются пустыми.

- app — composition root, Android lifecycle, самостоятельный manifest и выпуск.
- core — чистые модели Track/Profile, Catalog/PlaybackController, демокаталог
  и DemoPlaybackController. Идентификаторы треков квалифицированы источником.
- designsystem — темы PRISM, artwork-заглушка, transport controls и рамка фокуса.
- feature:shell — экраны, навигация и UI state. Получает контракты через ShellModel.

Демонстрационная реализация подключена явно в MainActivity. Нет автоматического
fallback с реального backend на fake. Play не создаёт MediaPlayer/Media3 и не
имитирует звуковой успех. В manifest не запрошены сетевые или файловые разрешения.
Кнопки, отсутствующие в M1 (вход, реальные клипы, updater), не изображают реализацию.

Source filter относится к выдаче; явная команда выбора playback source останавливает
плеер и ждёт Play. Queue item запускает выбранный доступный трек. Guest исключает
Яндекс. Смена профиля останавливает старую сессию; background work пока отсутствует.

Физическая идентичность beta/stable: dev.petrov.ymplayer2, собственный ключ подписи.
Для локальных автотестов — dev.petrov.ymplayer2.dev. Legacy applicationId, данные,
ключ, OAuth и updater не используются. Build выделяется только для выдаваемого APK;
внутренние debug-компиляции имеют явно ненумерованную internal-версию.

Навигация M1 — небольшой стек строковых маршрутов с SaveableStateHolder.
Каталожные детали сохраняют отдельный scroll; системный Back сначала закрывает
деталь. ViewModel владеет единым PlaybackController; оба вида плеера его наблюдают.
SavedStateHandle восстанавливает активную очередь после смерти процесса на паузе.
Сохранение на диск, профили с реальной авторизацией и service lifecycle — следующий этап.

Две панели плеера включаются с 960 dp и высоты 500 dp. Если контент ниже 520 dp,
окно короткое или fontScale >1.3, транспорт выводится перед компактной обложкой.
Это сохраняет первый Play на экране при 360×640 и коротком landscape. Детали каталога
в M1 открываются последовательно; полноценный list/detail layout отложен до реального
каталога. Большие коллекции и paging ещё не проверены.

Цена решения: демо не даёт доказательств аудио/API/USB/MediaSession/CWG/K4811.
Нативный UI и минимальные контракты можно проверить отдельно до этих интеграций.
