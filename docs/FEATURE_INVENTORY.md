# Карта функций и сценариев

Стабильный выпуск **2.4.1-build84** / Android9/API28. Настройки волны,
четыре источника, продолжение и режимы списков входят в основной stable канал.
[Базовая регрессия83](RELEASE_2_4_0_VERIFICATION.md), [patch84](PATCH_2_4_1_VERIFICATION.md).
Настройки доступны только активной «Моей волне», включая паузу; остальные
источники используют прежний переключатель, без кнопки настроек My Wave.
«1.x» — источник проверенного поведения, не зависимость приложения2.x.
S01–S11: [анализ reference](LEGACY_1X_ANALYSIS.md).
Текущая линия2.5: полноценный раздел эфирного Радио в ручном prerelease95.
Проверки реализации и подписанного APK завершены; stable84 не изменён. Владелец выбрал вариант1;
шоу/коллекция радиотреков исключены. Существующий OAuth подтверждён для
личного чтения в86; реальная запись требует приёмки. [Проверки](RADIO_2_5_VERIFICATION.md).

## Обязательные сквозные сценарии UI

1. Первый запуск → локальная музыка без Яндекс-аккаунта либо вход в профиль.
2. Выбор источника → явный Play → фон → возврат к тому же состоянию.
3. Во время музыки открыть каталог/альбом/поиск; навигация не останавливает плеер.
4. Открыть очередь и перейти к треку, затем вернуться в прежнее место каталога.
5. Офлайн: видеть доступное избранное/USB; сетевые данные не выдавать за доступное аудио.
6. Сменить профиль: сохранить checkpoint, остановить его playback, отменить его
   запросы; поздние ответы не попадают в новый профиль. Новый источник ждёт Play.
7. Потерять сеть или USB: понятная причина и путь восстановления, без вечного spinner.
8. Открыть клипы: аудио и видео не звучат одновременно; возврат без неожиданного Play.
9. Управлять теми же действиями тачем и пультом; Back возвращает фокус в исходную строку.
10. Установить 2.x рядом с 1.x; обновить beta 2.x до stable 2.x с сохранением данных 2.x.

Новая медиатека — индекс метаданных, а не команда скачать всю коллекцию.
Для Яндекса сохраняется постоянный кэш только избранного; локальные файлы не
копируются в него. Пустые/неподдерживаемые поля (например жанр) показываются честно.

Beta94: клипы возвращаются в исходный раздел по системному Back и кнопке видео,
включая восстановленную Activity. Обе карусели Радио догружаются автоматически;
ручная кнопка More удалена, Retry сохраняется. [Проверки](CLIP_BACK_2_5_VERIFICATION.md).

Beta95: сетевые разделы показывают отсутствие интернета через5 секунд и Retry;
local/USB/offline исключены. Автоматическое обновление каталога не включает
остановленный плеер или аудио за видеоплеером. [Проверки](INTERNET_2_5_VERIFICATION.md).
