# M7.6 — плотность карточек плейлиста

Дата: 2026-09-24. Исправление оформления по снимку владельца после build20.

В карточке трека название и кликабельный исполнитель занимают две компактные
строки рядом с обложкой. Для исполнителя убрана лишняя минимальная высота
`TextButton`; переход в его карточку сохранён. Источник и длительность перенесены
из отдельной строки в свободное место по центру ряда отметок, очереди и меню.
У строк без этого ряда сведения остаются возле названия. Логика воспроизведения,
отметок и записи плейлистов не менялась.
