# 2.0.2-build62 — поиск по офлайн-кэшу

Дата: 2026-10-01. Владелец обнаружил, что выбор «Офлайн» в поиске открывает
медиатеку. Причина подтверждена в ShellApp: кнопка обоих экранов вызывала
`navigate("offline")` и не являлась фильтром поисковой выдачи.

## Исправление

На маршруте search кнопка меняет источник выдачи и остаётся на том же экране.
CatalogScreen в этом режиме читает только скачанные доступные треки текущего
профиля из OfflineMusic: без SQLite-каталога устройства/USB и без запросов
OnlineMusic. Поиск нечувствителен к регистру и учитывает название, исполнителя
и альбом. Треки используют существующую компактную карточку и команды плеера.

Поисковая строка хранится в ShellApp отдельно для профиля и передаётся обоим
экранам поиска: текст сохраняется при переключении общего каталога, Яндекса
и кэша. Выбранный «Офлайн» отображается активным. На маршруте library кнопка
по-прежнему открывает управление офлайн-коллекцией и синхронизацией.
Алгоритмы загрузки кэша, OAuth и аудиодвижок не изменены.

## Проверка

`assembleDebug`, `assembleDebugAndroidTest`, `lintDebug` прошли.
Семь CatalogSourcesTest прошли на каждом из двух эмуляторов:
[Android 15 / emulator-5554](qa/offline-search62/android15.txt),
[Android TV 29 / emulator-5556](qa/offline-search62/android-tv29.txt).
Тесты используют реальные SAF/Media3 и явный debug-only API fixture,
не обращаются к личному аккаунту Яндекса.

Новый `offlineSourceSearchStaysInSearchAndFiltersOnlyProfileCache` проверяет:

- маршрут остаётся search, экран offline_list не появляется;
- введённый запрос и состояние выбранного источника сохраняются;
- название/исполнитель/альбом находят скачанный трек без учёта регистра;
- локальные файлы и нескэшированный онлайн-трек не попадают в выдачу;
- несовпадающий запрос даёт пустую выдачу;
- запросы к provider при офлайн-поиске не выполняются;
- текст переносится между источниками, после смены профиля чужой кэш не виден.

Первый телефонный прогон остановился на попытке теста выбрать источник при
открытой IME на коротком окне: строка источников в этом режиме скрыта по
существующему правилу. Тест исправлен командой IME Search перед сменой источника;
повторные полные семь сценариев на обоих эмуляторах прошли.
