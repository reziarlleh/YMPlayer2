# Кнопка Моей волны сохраняет очередь — B-050, build144

замечание после143. Владелец уточнил: это общее правило любой кнопки Моей волны,
а не только перехода из Локального. 144 принят и опубликован 14 ноября 2026; Latest/feeds —2.8.0-build144.
[Публикация/форум](RELEASE_2_8_0_VERIFICATION.md).

## Причины

1. В playMyWave повторный выбор активной волны безусловно вызывал startWave.
   Он очищал bookmark, готовое аудио, трек и позицию. После контекстного выбора
   аккаунта switchProfile уже восстановил его волну на паузе, поэтому этот путь
   тоже ошибочно считался перезапуском. Через клипы вызова playMyWave не было.
2. В GUEST-ветке reconcileOnline локального профиля cancelWave(discardAudio=true)
   вызывал общий WaveAudioBuffer.clear, удаляя готовые файлы другого профиля.
   После устранения первой причины позиция/очередь вернулись, но тест выявил
   потерю подготовленного аудио. Это отдельная связанная причина повторных загрузок.

## Исправление

- Для активной Моей волны с прежней станцией и набором seeds вызывается обычный
  playSession: игра продолжается, пауза возобновляется с той же позиции; повторное
  нажатие во время начальной загрузки не отменяет уже выполняющийся запрос.
- Для другой текущей функции восстанавливается валидный bookmark Моей волны.
  Только пустая очередь после Stop, отсутствие сохранённой волны или изменённые
  настройки требуют нового start. Применённое настроение меняет волну сразу.
  Применение тех же параметров без изменения не сбрасывает её.
- Очистка буфера из команд плеера ограничена текущим profileId. Локальный не
  удаляет готовую волну Яндекс-профиля; проверка account/profile для чтения сохранена.
  Внутренний общий clear без параметра остаётся для cleanup тестовых подставок.
- ShellApp, авторизация, видеодвижок и политика старта приложения не менялись.
  Обычная смена пользователя всё ещё восстанавливает паузу. Безусловного Play нет.
