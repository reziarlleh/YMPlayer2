Расширенная история/массовые операции F17, оставшиеся неподтверждённые API F25
и внешние скины не добавляются в этот выпуск. Скины/темы/руководство — 2.1.0.
Независимые приёмки и границы фикстур сохраняются в документах после stable;
слово stable не превращает их в проведённые физические испытания.

## Выпуск завершён

Подписан и опубликован `2.0.0-build57` тем же ключом и package; GitHub release
stable/latest, общий и stable-манифесты опубликованы. Настоящий установленный
клиент 56 получил 57, загрузил APK резервной кнопкой и обновился через Android
PackageInstaller с сохранением каталога, трека, позиции и первой даты установки.
Stable57 проверил свой канал, подписанное WAV-аудио/фон/системные кнопки и
холодное восстановление на паузе прошли. [Доказательства M12.8](M12_8_VERIFICATION.md).

Обязательных программных работ перед первым 2.0.0 не осталось. Независимые
приёмки выше не скрыты и не блокируют выпуск по прямому указанию владельца.
