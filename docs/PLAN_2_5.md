# 2.5 — эфирное Яндекс Радио

План2026-10-06 по уточнению владельца. Текущая линия — **2.5.0beta** на `main`,
без отдельной ветки и без отката исправлений2.4. Стабильная база/auto-update —
**2.4.1-build84**. Beta не меняет stable feeds и не становится GitHub latest.
Рабочий релиз2.5 будет подготовлен после проверенной реализации.

## Первый утверждённый этап

Достоверно проверить существующий токен текущего профиля в **эфирном** Радио,
чтобы определить возможность синхронизации личного избранного/коллекции.
Токен находится только в приложении на смартфоне владельца. Прототип должен
исполняться внутри того же пакета и Keystore, без экспорта токена и без другого
Device Flow. Первую beta можно установить поверх stable, данные сохраняются.

- HTTP-адреса личного FM-избранного подтверждены сетевым обменом frontend.
- Python-прототип и анонимные/неверные-token контроли выполнены.
- Собрана **2.5.0beta-build85**: ручная кнопка в диагностике, read-only запросы,
  проверка сохранённого UID/Music/FM, отчёт без секретов, экспорт существующим способом.
- Успех чтения коллекции и совпадение аккаунта учитываются отдельно; пустое
  избранное допустимо. Ответ200 от анонимного `/account/about` не считается входом.
- Действующий смартфонный токен ещё не проверен. Авторизованный результат нельзя
  заменять стендовыми ответами или другим вновь полученным токеном.
- Подписанная установка поверх84 проверена на API28 и TV29.19 целевых native
  проверок прошли, debug/release lint без ошибок. Это готовность прототипа,
  а не подтверждение принятия смартфонного токена FM-сервисом.

## После результата прототипа

Решить, подходит ли существующая авторизация для FM. При успехе следующие
предлагаемые этапы — каталог/поиск/города, ограниченный live-плеер с reconnect
и метаданными, личные любимые станции/коллекция. Уточнить состав экранов и
операции записи; сейчас они не реализованы. Не считать FM-реакцию emoji
лайком/запретом трека Музыки. Эфир не является конечной трековой очередью,
не использует repeat/shuffle или офлайн-синхронизацию эфирного потока.

B-006 остаётся независимым исправлением текущей линии после проверки токена;
параллельную ветку2.4 не создавать. Общие ожидания K4811/4PDA/Google Play
не относятся к допуску прототипа и не запускаются им.
