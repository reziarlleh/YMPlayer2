## Реализация

Отдельный модуль localization: **575 шаблонов**, полный English по умолчанию,
Russian в values-ru. Auto первый и по умолчанию, далее English (English),
Russian (Русский). Список упорядочен по английским названиям. Auto выбирает
поддерживаемый язык из системного списка, при отсутствии такого — English.
Выбор общий для устройства, хранится отдельно от профилей и скинов.

Переведены подписи экранов, кнопки и доступность, сообщения/ошибки, настройки,
вход, коллекции, скины, обновлятор, донат, клипы, уведомления и подписи сайдбара.
Metadata и технический журнал сохраняют исходные значения. Неизвестные подписи,
уже записанные как метаданные старого каталога, также не переписываются.
Исправлена устаревшая подсказка после входа: музыка Яндекса уже доступна в
медиатеке и поиске, а не ожидается «на следующем этапе».

Ключевые шаблоны передают значения отдельными параметрами и не переводят их.
Для legacy-строк core есть адаптер на границе UI. Известные составные ошибки
волны и редактирования обрабатываются отдельно. Ранее показанные английские
статусы можно перерисовать при возврате к Russian; неоднозначный короткий
английский алиас не выбирается наугад.

Смена языка наблюдаема из Compose, не сбрасывает route и не пересоздаёт engine.
Native-клипы перерисовывают подписи по AppLanguages.state, не запускают новый
контроллер или клип. Уведомление офлайн-синхронизации и активный сайдбар
обновляют текст по тому же состоянию. Чистый JVM core и алгоритмы API/кэша/
аудио/видео не менялись. Коррекции интерфейса 2.1.2–2.1.5 сохранены.

## Проверки

Генератор --check: **575 сообщений, два полных пакета**, уникальные ключи,
те же индексы параметров, обязательная форма other, файлы соответствуют каталогу.
Debug/test APK собраны. Подготовка источников обнаружила обычные ошибки
автоматического извлечения: inline Gradle dependencies требовали разделителя,
тексты двух const val требовали вычисляемых getter. Исправлены до выдачи Build;
генератор каталогов не редактирует Kotlin UI или Gradle-файлы.

На **YM2_M1_Phone / Android 15 и YM2_M1_TV / Android 10**:

- [Первая выборка](qa/m14-localization/phone-regression.txt) /
  [TV](qa/m14-localization/tv-regression.txt): **15/15 на каждом**.
  Пять LocalizationTest проверяют живую смену текста, порядок языков,
  повторное чтение сохранённого выбора, Auto/fallback, звучащий WAV без потери
  профиля/позиции/качества/кэша, D-pad и неизменность музыкальных названий.
  Остальные — четыре AboutTest, навигация пультом через прогрессбар, две
  выбранные строки каталога, поиск по офлайн-кэшу, разделение настроек/списка
  и синхронизация с воспроизведением при отключённой сети.
- После уточнения обработки сохранённых статусов:
  [финал телефон](qa/m14-localization/phone-final.txt) /
  [TV](qa/m14-localization/tv-final.txt): **7/7 на каждом**.
  Пять LocalizationTest повторены; два ClipRemoteProgressTest проверили
  настоящий MP4, пульт и отсутствие затемнения следующего клипа прогрессом.
  Всего **17 разных сценариев на каждом** с учётом пересечения выборок.

Начальная выборка языка дала 4/5: тест native-клипов ожидал «NEXT», хотя
контекстный перевод — «UP NEXT». Исправлено ожидание, а не подпись приложения;
[первый лог](qa/m14-localization/phone-initial.txt) сохранён.
Тесты изолированы отдельными preferences и WAV/MP4-фикстурами. Личный аккаунт,
