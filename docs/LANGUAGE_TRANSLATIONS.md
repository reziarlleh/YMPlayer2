# Как устроены переводы интерфейса

Первый этап 2.2.0 содержит English и Russian. Auto использует поддерживаемый
язык из системного списка; если такого нет — English. Выбор общий для устройства,
не для профиля, и сохраняется после закрытия приложения.

Исходник: [каталог](../localization/catalog.json),
[готовые языки](../localization/languages.json),
[генератор](../tools/Generate-Translations.py).
Каталог хранит стабильный ключ, исходный русский шаблон, английскую формулировку
и места использования. Android XML и enum Msg генерируются из него.

Перед сборкой после изменения переводов:

```powershell
python tools/Generate-Translations.py
python tools/Generate-Translations.py --check
```

Генератор прекращает работу при пропущенном переводе, дублировании ключа
или изменении набора параметров. Команда --check не пишет файлы и обнаруживает
расхождение каталога и сгенерированного кода. Обычная Gradle-сборка использует
закоммиченные результаты, не зависит от установленного Python.

Параметр `@0@` — непрозрачное значение: название музыки, версия, длительность
или другой аргумент. Индексы можно переставить под грамматику языка, но нельзя
удалять или добавлять. `@0|track@` вставляет количество с нужной формой слова
из trackCount. Не разрезать предложения на переводимые отдельные слова.
Действие «никогда не предлагать» отличается от удаления лайка или файла.

Для нового пакета добавьте в каждую запись каталога
`"translations": {"de": "контекстный перевод шаблона"}` (с нужным кодом),
затем запись в languages.json с tag, englishName, nativeName и trackCount.
Генератор создаёт `values-de` и регистрирует полный пакет в SupportedLanguages.
Auto остаётся первым, языки сортируются по englishName.
Новый язык объявляется готовым после проверки приложения и формулировок.

English доступен в обычном выпуске 2.2.0-build71 без beta. Перед расширением
пакетов учитываем проверку владельца; уточнения и языки выпускаем в 2.2.x.
Окончательный порядок: Auto, Belarusian (Беларуская), English (English),
French (Français), German (Deutsch), Kazakh (Қазақша), Russian (Русский),
Spanish (Español), Ukrainian (Українська).

В текстах UI используйте `tr(Msg.key, arguments…)`. Старые сообщения core
адаптируются в месте отображения через trMessage/trIssue; музыкальные метаданные
и имена импортированных скинов в эти адаптеры передавать нельзя.
Нативный элемент должен обновить подписи при изменении AppLanguages.state.
Нельзя менять ID профиля, названия папок/файлов или протоколы вместе с языком.
При добавлении новых пакетов также проверьте ранее показанные статусы при смене
языка в обе стороны; текущие legacy-алиасы охватывают первый English/Russian этап.
