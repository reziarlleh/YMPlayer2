# M13 — пользовательские скины в 2.1.0

Старт этапа после финального 2.0.1. Основа — `AppSkin` и встроенный «Оксид».
Ни импорт, ни готовые внешние темы пока не объявляются реализованными.

1. Зафиксировать формат пакета: manifest с версией контракта, автором и названием,
   семантические Light/Dark-токены, векторные значки по `UiIcon` и оформление
   заглушек. Подготовить редактируемый шаблон «Оксид».
2. Реализовать чтение и проверку пакета в модуле оформления. Ограничить размеры
   файлов, проверить пути внутри архива, цвета, векторы и совместимость версии;
   неполные наборы значков получают встроенный fallback.
3. Добавить импорт через системный выбор файла, экран preview и явное применение.
   Выбор сохраняется после перезапуска; ошибка возвращает рабочий «Оксид».
4. Распространить выбранный контракт на Compose и native-панель клипов, не меняя
   диагональную композицию, надписи, команды, hit targets и правила TV-фокуса.
   Отдельная белая панель K4811 сохраняет требования владельца.
5. Проверить смену оформления во время настоящего WAV/HLS-воспроизведения,
   профили, фон, поворот, D-pad и 200% текст; playback/кэш/авторизация неизменны.
6. Выпустить несколько готовых тем, подробное руководство и шаблон для авторов
   вместе с проверками реального импорта. Сквозной Build продолжается после 60.

Формат векторов и точный schema закрепляются до написания импортера. Пакет
содержит только визуальные данные; маршруты, команды и provider остаются кодом
приложения. Системный launcher/TV banner сохраняют официальную айдентику продукта.

Критерий выпуска 2.1.0: пользователь без изменения исходников может создать,
импортировать, увидеть и применить свою тему; некорректный пакет не мешает
воспроизведению и запуску. Одних встроенных палитр недостаточно для закрытия M13.
