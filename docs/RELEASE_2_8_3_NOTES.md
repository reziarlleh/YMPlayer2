# YMPlayer2 2.8.3 — полный состав изменений

Ручной кандидат **2.8.3-build150**, не опубликованный стабильный релиз.
[Цели цикла](PLAN_2_8_3.md), [аудит и доказательства](AUDIT_2_8_3_VERIFICATION.md).
Готовность подписанного APK и результаты установки фиксируются отдельно.

- Исправлена отправка событий воспроизведения волны: используются JSON,
  подходящий session/station endpoint, время ISO8601 и длительность для dislike.
  Каждый подготовленный трек сохраняет контекст своей сессии после перезапуска;
  прежние сохранения очереди читаются совместимо.
- Пересоздание аудиослужбы больше не отменяет ещё действительный запрос запуска
  от открытого приложения. Более поздняя Pause/Stop и смена профиля сохраняют
  приоритет; тихая подготовка сама по себе звук не включает.
- Выбор пустого офлайн-кэша системным медиаклиентом фиксирует пустой источник
  и не возвращает прежний список. Подключение движка корректно определяется
  даже при отсутствии метаданных/аккаунта для сохранённого офлайна.
- Исправлен запуск локального списка после офлайна: файлы проверяются по новому
  источнику, прежняя закладка сохраняется до успешного выбора.
- Проведён аудит границ модулей, хранения и фоновых задач. Удалён подтверждённый
  неиспользуемый метод, исправлены устаревшие сведения в документации.
  Функциональные модули, восемь языков и Android6+ сохранены.

Данные и переносимый кэш сохраняют прежний формат. Новых функций из будущего
плана в этот цикл не добавляли. Исправление клиентского протокола не является
гарантией доступности серверов Яндекса или закрытием каждого старого личного отзыва.
