# YMPlayer 2 · 2.1.1-build65

В настройках «Мне нравится · офлайн» появился выключатель кэша для всего устройства. На телевизоре, который всегда онлайн, кэш можно отключить. Синхронизация остановится, ранее скачанные файлы можно удалить кнопкой на той же странице. Онлайн-музыка и предзагрузка волны продолжают работать.

Исправлено управление волной клипов с пульта: стрелки и OK возвращают скрытую панель, затем работают по фокусу. Кнопки Play/Pause и перехода между клипами тоже работают.

Прогресс клипа теперь виден по затемнению фона текущего трека слева направо. Блок следующего клипа не затрагивается.

Уточнено описание самостоятельной ветки 2.x и обновлено [руководство пользователя](https://github.com/reziarlleh/YMPlayer2/blob/main/docs/USER_GUIDE.md). Для работы 1.x не требуется.

Проверено на проектных эмуляторах Android 15 и Android TV 29, включая установку подписанного APK поверх build64 и сохранение выключенного кэша после перезапуска.
