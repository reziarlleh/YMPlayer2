## Будущие версии

### Завершённый этап1 — исправления и улучшения существующего поведения

1. [x] **Волна и ранний Next.** Окно до10, полное временное аудио всей очереди,
   текущий/следующий первыми, сохранён Previous. Исправлены восстановление всего
   окна, смешение будущего кэша с услышанным и ограниченный проход эхо-выдачи.
   Обычные списки любой длины целиком не скачиваются. D-006 не приравнен
   автоматически к прежнему B-037 или к доказанному персональному случаю.
2. [x] **Восстановление Play.** Исправлены сохранение намерения до медленной
   команды, тихий reconnect, ошибка потока и radio→music handoff. Ручная Pause/Stop
   остаётся паузой/остановкой. Физический ночной сценарий D-004 не заявляется проверенным.
3. [x] **Фокус.** Обновление трека не забирает фокус; отключение выбранной Next
   оставляет фокус в транспорте. Конкретный сценарий автора B-038 не воспроизведён
   на его устройстве, найдена и убрана безусловная смена фокуса в клиенте.
4. [x] **Планшетная компоновка.** Управление слева, обложка/сведения справа;
   проверены API35 1024×600 и TV1920×1080, сохранён фиксированный экран.
5. [x] **Три пиктограммы источников.** Волна/Офлайн/пользовательский список
   (сейчас локальное избранное), отдельное название источника/списка. Настройки
   только настоящей Моей волны. Третий слот имеет UI-контракт для будущего выбора;
   настройка назначения и новое сохранение локального списка пока не реализованы.
6. [x] **Авто/Максимальное.** Сверены с реальным выбором лучшего доступного
   битрейта, исправлены8 переводов и обе инструкции. Сетевая адаптация не добавлялась.

### Этап2 — функциональные нововведения

- [ ] **Автоматический переход между сетью и локальной музыкой.** Принятое
  обещание№90 по запросу№88: отдельная выключаемая настройка для перехода
  к офлайн-кэшу/локальному списку при потере сети и обратного возврата к волне.
  Перед реализацией выбрать источник подмены, защиту от коротких провалов/
  медленной сети и правила возврата с учётом ручной паузы и смены источника.
- [ ] **Текст песни.** Добавить кнопку показа текста текущей песни, если текст
  доступен. Источник текста и вид окна определить при подготовке задачи.
- [ ] **Переключение радиостанций.** Кнопками «Предыдущий»/«Следующий» листать
  станции, как треки в музыкальном плеере. Какой список станций листается и
  поведение на его границах уточнить перед реализацией.
- [ ] **Последний локальный список.** Добавить быстрый переход к сохранённому
  локальному списку. Основа обсуждения — явная команда сохранения текущей
  полностью локальной/USB-очереди; переходы к другим источникам этот выбор
  не заменяют. [Разбор и границы](LOCAL_SOURCE_SHORTCUT_REVIEW_2026_10_20.md).
  Предусмотреть возврат к прежнему треку/позиции по пожеланию№92. Сохранение
  состава/порядка и восстановление позиции — отдельные части задачи;
  окончательные правила возобновления согласовать перед реализацией.
  Согласовать этот сценарий с возможным настраиваемым третьим слотом источника:
  пользовательский локальный список/плейлист, включая локальное избранное.
  Не создавать конкурирующие неявные назначения одной кнопки.
- [ ] **Несколько аккаунтов.** Переработать существующие профили для удобной
  работы с произвольным количеством аккаунтов и быстрого переключения между
  ними — уточнение владельца из№77. Запрос№76 предлагает кнопки/иконки на
  главном экране; конкретный вид быстрого переключения ещё не выбран.
  Существующую независимую авторизацию профилей не считать новой реализацией
  этого улучшения; конкретный интерфейс и правила переключения ещё предстоит
  определить.

Первоначальные пять пунктов включены по указанию22 октября; аудит28 октября
добавил два пропущенных обещания. После уточнения владельца они распределены
между исправлениями/улучшениями и новыми функциями. Первый этап опубликован в124; перечисленные функциональные задачи
не реализованы. Стабильный выпуск и отложенные направления сохраняют свой статус.

### Предложения, требующие отдельного решения

- **Политика Плей / Авто / Пауза.** [Предложение владельца №99 и разбор5 ноября](STARTUP_POLICY_REVIEW_2026_11_05.md).
  Авто предполагается default и сохраняет нынешнее восстановление намерения.
  Плей/Пауза — отдельный явный выбор для нового запуска, без повторного действия
  при возврате из фона/повороте. Безусловный Play и имитация Pause→Play запрещены.
  Реализация, область музыки/радио/клипов и версия не утверждены; новая BOOT-функция
  не следует из этого обсуждения. D-004 остаётся наблюдением, не закрывается настройкой.
- **Quick play для закреплённых папок/листов.** Вариант№73/75 уже есть в
  [разборе локального доступа](LOCAL_SOURCE_SHORTCUT_REVIEW_2026_10_20.md);
  отдельным принятым этапом сверх явно сохранённого локального списка не является.
