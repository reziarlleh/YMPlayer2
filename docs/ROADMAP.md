   и класса волны14/14. Первоначальный timeout сохранён отдельно.
   Signed102 собран/установлен поверх101/API35; system/язык/раздел/трек сохранены.
5. Выполнено: публикация/latest/оба feeds, скачивание GitHub и резервного APK
   с совпадающим SHA256, проверка документов после push. Реальный updater98/API28

   отражены в датированном HTTP-срезе D-001; основной резервный APK доступен.
