# M8.2 — медиакнопки, аудиофокус и восстановление службы

Дата: 2026-09-24. Перенос F20 по [ADR-020](DECISIONS/ADR-020-media-button-resumption.md).

Добавлен `MediaButtonReceiver` Media3. После остановки `AudioService` кнопка Play
снова создаёт службу и возобновляет сохранённый локальный трек с его позиции.
Системный контроллер передаёт активной сессии Pause/Play/Next. Для возобновления
после удаления процесса и загрузки системы предусмотрен колбэк
`onPlaybackResumption` с метаданными checkpoint текущего профиля; запрос
метаданных не должен запускать воспроизведение. Точный результат этих сценариев
на устройстве владельца пока не подтверждён.

Существующая настройка ExoPlayer автоматически управляет аудиофокусом. При
временном захвате фокуса другим клиентом интерфейс теперь отражает подавление
аудио и возвращается к состоянию воспроизведения после возврата фокуса.
