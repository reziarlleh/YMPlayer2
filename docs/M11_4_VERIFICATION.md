# M11.4 — компактный checkpoint автоматической очереди

Дата: 2026-09-28. Выпуск: `2.0.0beta-build46`.

## Изменение

- При автоматическом следовании локальной библиотеке checkpoint теперь хранит
  режим, ID и позицию текущего трека, а из метаданных — только текущий трек
  для системного возобновления до загрузки индекса. Полный порядок заново
  строится из библиотеки при запуске службы. Старые полные checkpoints
  читаются прежним способом и перезаписываются компактно.
- Ручная очередь и волна по-прежнему сохраняют все свои ссылки: их порядок и
  источник нельзя восстановить из локального индекса.
- Плеер больше не держит отдельную карту метаданных всей библиотеки. Для
  ручной очереди при восстановлении и обновлении разрешаются только нужные ID;
  выбор трека, уже стоящего в очереди, не запускает полное перечисление
  каталога.

## Граница

Автоматическая очередь в работающем плеере **ещё содержит все локальные
треки**. Изменение сокращает запись checkpoint и одну дублирующую структуру,
но не делает размер очереди в памяти ограниченным. Порционное представление
очереди, совместимое с Next/Previous, shuffle/repeat, MediaBrowser и
восстановлением, остаётся следующим шагом M11. Также открыты объединение
источников Яндекс/локально/USB и проверка большой личной коллекции.
