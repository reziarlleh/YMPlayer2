# M12.2 — сквозное обновление приложения

Дата: 2026-09-28. Исходная сборка: `2.0.0beta-build40`; целевые сборки:
`2.0.0beta-build41` и `2.0.0beta-build42`.

Build41 опубликован в отдельном GitHub Release. Оба адреса APK (GitHub
Releases и версионный URL jsDelivr) отдали 4 672 774 байта и SHA-256
`13c82bd84d10e66e1eca42766bb5675bb0c54f5d0a7607a40b732cc9e1078ea4`.
Основной манифест отдал build41. Манифест jsDelivr по `@main` продолжал
отдавать build40 сразу после выпуска; согласно документации CDN, ветки
кешируются до 12 часов. Резервный источник работает с задержкой появления
новой версии, хотя версионный APK доступен сразу. Проверка доступности из
сети владельца ещё открыта.

На Android 15 эмуляторе установленный build40 выполнил ручную проверку в
приложении, показал build41, скачал APK с GitHub, запросил у Android право
установки из этого источника и открыл системный экран обновления. После
подтверждения установлен `versionCode=41`, `versionName=2.0.0beta-build41`;
`firstInstallTime=2026-09-09 07:09:25` сохранился, новая сборка открылась.
Это проверяет путь через сам updater и системный установщик, но не доказывает
работу на физическом K4811/HyperOS. Перед этим эмулятор терял DNS; после
перезапуска с действующими DNS оба домена разрешались, и повторная проверка
прошла. Ошибка сети была корректно показана приложением без сбоя плеера.

Build42 подписан и опубликован. Три инструментальных теста `UpdateClientTest`
прошли после исправления закрытия соединения при неполном HTTP-редиректе;
`assembleRelease` и `lintVitalRelease` прошли. Оба опубликованных адреса,
GitHub Releases и версионный jsDelivr, отдали APK размером 4 672 778 байт и SHA-256
`fe70edcd7975de397b43982b08ae181dd201d0fa24702cbe27ef81bd83899117`.
Основной манифест отдал build42, а манифест CDN `@main` всё ещё отдавал
build40 в момент проверки.

На том же эмуляторе build41 нашёл build42 через ручную проверку и загрузил
его именно кнопкой «Скачать через резервный источник». Системный установщик
показал запрос обновления; после подтверждения установлен `versionCode=42`,
`versionName=2.0.0beta-build42`, приложение открылось. Исходный
`firstInstallTime=2026-09-09 07:09:25` сохранился. Это подтверждает реальный
путь резервного APK в приложении, но не свежесть резервного манифеста сразу
после выпуска и не доступность CDN в сети владельца.

Автопроверка по суточному интервалу и выключатель покрыты UI-проверкой,
но отдельный цикл автоматического предложения новой версии на устройстве
ещё не проверялся. Физическая установка на K4811/HyperOS, миграции данных и
полная выпускная регрессия остаются открытыми до 2.0.0.
