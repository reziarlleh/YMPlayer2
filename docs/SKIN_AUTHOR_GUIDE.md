# Как создать свой скин

Скин меняет цвета, значки Compose и палитру заглушек обложек. Плеер, очереди,
профили, кеш, авторизация, подписи и действия кнопок остаются приложением.
Диагональная native-панель клипов принимает тёмные цвета скина; её композиция
и кнопки сохраняются. Launcher/Android TV banner не заменяются. K4811 сохраняет
белые кнопки и своё оформление независимо от музыкального скина.

## Быстрый старт

1. Скачайте [шаблон](../skins/oxide-template.ymskin) или скопируйте папку
   [oxide-template](../skins/oxide-template/manifest.json).
2. Распакуйте ZIP. Откройте `manifest.json` обычным текстовым редактором с UTF-8.
3. Измените `id`, `name`, `author`, затем нужные цвета. Не используйте `prism`,
   `harbor`, `olive`, `silver`: это встроенные ID.
4. Упакуйте **содержимое** папки: в корне ZIP должен быть `manifest.json`,
   не внешний каталог. Назовите файл `my-theme.ymskin`.
5. В приложении откройте **Настройки → Скины → Импортировать .ymskin**.
   Выберите файл системным файловым менеджером.
6. Проверьте тёмный и светлый предпросмотр. До «Применить» активная тема не меняется.
7. Нажмите «Применить», проверьте экраны, крупный текст и читаемость фокуса пульта.
   Выбранный пакет сохраняется внутри приложения и переживает перезапуск.

При наличии Python 3.9+ можно упаковать командой из корня репозитория:

```console
python tools/Pack-Skin.py skins/oxide-template my-theme.ymskin
```

Упаковщик проверяет пути и размеры, но окончательную совместимость проверяет
импортёр приложения. Он не требует Android SDK или пересборки APK.

## Manifest и цвета

Минимальный скин наследует весь «Оксид», кроме указанных токенов:

```json
{
  "schemaVersion": 1,
  "id": "my-copper",
  "name": "Моя медь",
  "author": "Имя автора",
  "description": "Краткое описание",
  "dark": {"primary": "#C98D60"},
  "light": {"primary": "#86502D"}
}
```

Цвета непрозрачные, строго `#RRGGBB`; прозрачность native-панелей задаётся
приложением. `dark` и `light` независимы. Неполный объект наследует неуказанные
значения базового режима. Неизвестное имя — ошибка, а не молчаливый fallback.

| Токены | Где используются |
| --- | --- |
| `primary`, `onPrimary` | Главные кнопки, активные значки, фокус и надпись на них |
| `primaryContainer`, `onPrimaryContainer` | Выбранные элементы, текущая панель клипа |
| `secondary`, `onSecondary`, `secondaryContainer`, `onSecondaryContainer` | Второстепенные элементы, следующая панель клипа |
| `tertiary`, `onTertiary`, `tertiaryContainer`, `onTertiaryContainer` | Дополнительные акценты Material3 |
| `background`, `onBackground` | Фон и основной текст |
| `surface`, `onSurface`, `surfaceVariant`, `onSurfaceVariant` | Карточки, диалоги, второстепенный текст |
| `surfaceContainerLowest`, `surfaceContainerLow`, `surfaceContainer`, `surfaceContainerHigh`, `surfaceContainerHighest` | Уровни поверхностей Material3 |
| `surfaceDim`, `surfaceBright`, `surfaceTint` | Дополнительные уровни фона/тон поверхности |
| `inverseSurface`, `inverseOnSurface`, `inversePrimary` | Контрастные обратные поверхности |
| `error`, `onError`, `errorContainer`, `onErrorContainer` | Ошибки и предупреждения |
| `outline`, `outlineVariant`, `scrim` | Границы и затемнение |

Используйте достаточный контраст: основной текст относительно фона желательно
не ниже 4.5:1, акценты, значки и фокус не ниже 3:1. Приложение не подменяет
заданные цвета автоматически. Проверяйте реальные экраны: короткий preview
не содержит всех состояний ошибок, диалогов и каталога.

## Векторные значки

Добавьте соответствие роли и JSON-файла в `icons`:

```json
"icons": {"PLAY": "icons/play.json", "PAUSE": "icons/pause.json"}
```

Пример `icons/play.json`:

```json
{
  "width": 24,
  "height": 24,
  "paths": [{"data": "M 6 3 L 21 12 L 6 21 Z", "fillType": "nonZero"}]
}
```

`width`/`height` — размеры viewport, не размер кнопки. Значок масштабируется
в существующее место, области нажатия остаются 48/64 dp. Цвет значка задаётся
UI. Для пустых отверстий используйте `evenOdd` или направление контуров.
Обводку предварительно преобразуйте в замкнутый залитый контур в векторном
редакторе. Из SVG переносите `d` каждого `path`; примените transform к координатам
перед экспортом. Градиенты, маски, SVG-скрипты, URL и изображения не поддерживаются.

Допустимые роли (имена чувствительны к регистру):

```text
PLAYER LIBRARY SEARCH CLIPS PROFILE GUEST SETTINGS BACK FORWARD
PLAY PAUSE STOP PREVIOUS NEXT QUEUE NOW_PLAYING FOLDER EXPAND
CLOSE CHECK CHOICE_ON CHOICE_OFF REPEAT REPEAT_ONE SHUFFLE
EDIT UP DOWN REMOVE DRAG_HANDLE ADD_QUEUE CLEAR_QUEUE ARTWORK
FAVORITE FAVORITE_OFF MORE PLAYLIST ADD BLOCK WAVE
DISLIKE DISLIKE_OFF UNKNOWN REFRESH EQUALIZER BRAND
```

Если роль отсутствует, показывается встроенный значок. `FAVORITE` и
`FAVORITE_OFF`, `DISLIKE` и `DISLIKE_OFF` должны различаться; их состояние
и принадлежность треку/артисту по-прежнему задаёт приложение. `ARTWORK` —
декоративная заглушка, `BRAND` — значок внутри Compose-интерфейса; они не
заменяют системный launcher или TV-плитку. Полный логотип с названием приложения
в заголовке и «О приложении» — общая айдентика, а не роль `BRAND`; его надпись
подбирается под светлый/тёмный фон. Значки native-клипов и K4811
не входят в карту Compose `UiIcon`.

## Заглушки обложек

```json
"artwork": {
  "backgrounds": ["#533426", "#454337", "#36302A"],
  "end": "#191715"
}
```

Список содержит 1–12 цветов; приложение выбирает один по треку и строит градиент
к `end`. Обложки, полученные от локального файла или Яндекса, не перекрашиваются.

## Ошибки и обновление своей темы

Импорт отклоняет неизвестную версию, опечатки полей, неверные цвета/векторы,
пропавшие файлы, лишние файлы, повторяющиеся ZIP-пути и превышение лимитов.
Полные ограничения: [формат v1](SKIN_FORMAT.md).
Отказ не меняет активный скин и не останавливает музыку.

Для новой редакции импортируйте пакет с тем же собственным `id`. После проверки
и «Применить» его сохранённая копия заменится. Отмена сохраняет прежнюю редакцию.
Скин можно удалить после переключения на другой. Для быстрого восстановления
есть «Вернуть „Оксид“». Если сохранённый активный файл повреждён, при следующем
запуске приложение выбирает «Оксид» и сообщает об этом в разделе скинов.
Удаление данных приложения удаляет импортированные темы вместе с его настройками.

## Примеры и распространение

[Готовые пакеты и исходники](../skins/README.md): «Гавань», «Олива», «Серебро»
и шаблон «Оксида». Внешняя копия встроенной темы должна получить собственный ID.
Для публикации укажите автора и лицензию в описании/сопроводительном документе;
документы лицензии распространяйте рядом с архивом, а не лишним файлом внутри.
Проверяйте тёмный/светлый режим, телефон/TV, D-pad и 200% текст. Пакет v1
не должен обещать изменение функций приложения: это исключительно оформление.
