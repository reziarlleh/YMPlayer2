# Проверка руководства пользователя

Дата: 2026-10-01. Выпуск: **2.1.0-build64**. Код приложения и APK не менялись.

[Руководство](USER_GUIDE.md) закрывает отдельный запрос владельца на пользовательскую
документацию; существующий SKIN_AUTHOR_GUIDE описывает создание пакетов и его
не заменяет. Ссылка на руководство вынесена в начало README.

В руководстве явно различены лайки трека/исполнителя/альбома, локальное избранное,
очередь и скачивание; только лайки треков синхронизируются в кэш. Перетаскивание
указано для плейлистов Яндекса; локальный редактор использует стрелки.
Волна не получает shuffle/repeat. Обновление требует действий пользователя.
Произвольное создание профилей и встроенный DSP не заявлены.

## Запрос изменения шапки 4PDA

Владелец попросил спрятать описание и возможности под спойлер. Подготовлена
[новая шапка](FORUM_TOPIC_4PDA.pending.bbcode): добавлен «Описание и возможности»
и ссылка на руководство; существующие вложения сохранены.

**Это ещё не опубликованная правка.** На текущем аккаунте reziarlleh кнопка
редактирования отсутствует, прямое открытие известной формы ответа возвращает
«Вы не можете редактировать это сообщение». Точная причина ограничения не
подтверждена. У владельца запрошено разрешение обратиться к модератору.
Отдельные сообщения в теме не создавались; FORUM_TOPIC_4PDA.bbcode сохраняет
последнюю подтверждённую опубликованную шапку.
