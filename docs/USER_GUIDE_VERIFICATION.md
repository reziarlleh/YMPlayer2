# Проверка руководства пользователя

2026-10-03: добавлена [английская инструкция](USER_GUIDE_EN.md) и история
прослушивания 2.3.0. Названия английских команд сверены с catalog.json;
основная страница проекта остаётся русскоязычной. Английская инструкция
использует существующие иллюстрации с явной подписью об их версии/русском языке,
а не выдаёт их за новые английские скриншоты. Действия истории сверены с
HistoryScreen/ListeningHistory/AndroidPlayback; проверки — в отчёте 2.3.0.

Дата: 2026-10-01. Исходное руководство подготовлено для **2.1.0-build64**,
без изменения кода/APK. Дополнено для **2.1.1-build65** после проверки patch.

[Руководство](USER_GUIDE.md) закрывает отдельный запрос владельца на пользовательскую
документацию; существующий SKIN_AUTHOR_GUIDE описывает создание пакетов и его
не заменяет. Ссылка на руководство вынесена в начало README.

После RepoWise context (CLI; MCP-запрос не завершился) проверены реальные источники:

В руководстве явно различены лайки трека/исполнителя/альбома, локальное избранное,
очередь и скачивание; только лайки треков синхронизируются в кэш. Перетаскивание
указано для плейлистов Яндекса; локальный редактор использует стрелки.
Волна не получает shuffle/repeat. Обновление требует действий пользователя.
Произвольное создание профилей и встроенный DSP не заявлены.

## Иллюстрации

- Четыре существующих необработанных PNG `publication/4pda/`: реальный интерфейс
  stable64 на проектных эмуляторах Android 15/TV 29. На снимке скинов также виден
  импортированный учебный пакет. Повторные снимки не требовались.
- `qa/patch-2-1-1/clip-tv-progress.png`: новый снимок native-панели и реального
  MP4 тестовой фикстуры на TV29. Позиция 75%, затемнена только текущая область.
  В debug-проверке используется та же реализация панели, что в signed65;
  происхождение обозначено в руководстве. Это не живой ответ Яндекса.
- 27 отдельных SVG экспортированы из исходников точной зависимости AndroidX
  без изменения геометрии. Источник, преобразование и лицензия сохранены рядом.

Проверены 57 ссылок/изображений и якоря содержания: отсутствующих локальных
целей нет. XML всех 27 SVG корректен; роли сверены с PrismIcons. Изображения
просмотрены. После push в main открыта публичная страница GitHub: руководство
отрендерено, все пять PNG и 27 SVG загружены, переход к справочнику кнопок работает.
Сборка, повторная
проверка аудио и физические устройства для этого изменения не использовались.

## Запрос изменения шапки 4PDA

Владелец попросил спрятать описание и возможности под спойлер. Подготовлена
[новая шапка](FORUM_TOPIC_4PDA.pending.bbcode): добавлен «Описание и возможности»
и ссылка на руководство; существующие вложения сохранены.

**Это ещё не опубликованная правка.** На текущем аккаунте reziarlleh кнопка
редактирования отсутствует, прямое открытие известной формы ответа возвращает
«Вы не можете редактировать это сообщение». Точная причина ограничения не
подтверждена. Владелец решил дождаться переноса темы и предоставления прав,
после чего актуализировать шапку. Обращение к модератору не отправляется.
Отдельные сообщения в теме не создавались; FORUM_TOPIC_4PDA.bbcode сохраняет
последнюю подтверждённую опубликованную шапку.
