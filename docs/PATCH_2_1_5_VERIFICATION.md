# 2.1.5 — настройки кэша отдельно от медиатеки

Дата: 2026-10-02. По замечанию владельца убрана лишняя ссылка из настроек
на папки с музыкой, разделены управление офлайн-кэшем и прослушивание.

## Изменение

В настройках полноширинная кнопка **Настройки офлайн-кэша** открывает отдельный
экран с выключателем кэша, Wi-Fi, синхронизацией, её остановкой, результатом
и очисткой файлов. Список треков и кнопка воспроизведения здесь не показываются.
«Назад», включая системную кнопку пульта, возвращает в настройки.

**Медиатека → Офлайн** содержит список сохранённых треков, счётчик и команду
«Слушать сохранённое». Здесь нет настройки Wi-Fi, выключателя, синхронизации
или очистки. Пустой список объясняет состояние кэша; действия по настройке
не подменяют медиатеку. «Назад» возвращает в медиатеку.

Папки с музыкой подключаются через **Медиатека → Общий каталог → Папки с музыкой**.
Качество аудио по-прежнему выбирается отдельно в **Настройки → Качество звука**;
подсказка об удалении готового кэша исправлена под новый путь.

Разделение выполнено в shell: новый OfflineSettingsScreen, сокращённый
OfflineScreen и маршруты с разными родительскими разделами. Core, provider,
playback, формат файлов и алгоритмы синхронизации не менялись. Переноса данных
нет. Выключатель устройства, изоляция профилей, сохранение файлов при выключении
и сохранение серверных лайков при очистке действуют как прежде.
2.2 остаётся на паузе; форум ждёт прав на редактирование шапки.

## Проверки

**7/7 на YM2_M1_Phone / Android 15 и 7/7 на YM2_M1_TV / Android 10**:

- Раздельные экраны, полная ширина кнопки, отсутствие папок в настройках,
  выбранный раздел меню и возврат в соответствующего родителя.
- Гостевой профиль: пустой список без чужих треков и доступный общий выключатель.
- Пульт: открытие настроек, выключение/включение, системный Back и выбор трека.
- Выключение без удаления файлов, включение и повторное появление списка.
- Синхронизация из настроек, воспроизведение из медиатеки при отключённой сети,
  переход ко второму треку и восстановление на паузе без сетевого разрешения URL.
- Очистка офлайн-файлов с сохранением лайков на сервере.
- Иерархический возврат в локальном каталоге и доступ к папкам из медиатеки.

[Телефон](qa/patch-2-1-5/phone-tests.txt) · [TV](qa/patch-2-1-5/tv-tests.txt).
Использованы изолированные профили, локальные WAV и тестовые обложки; личный
аккаунт Яндекса и физические устройства не использовались. Debug/test APK собраны.
Новая проверка фокуса переводит Android из touch mode событием D-pad перед
активацией; это состояние тестового ввода, не обход ошибки приложения.
