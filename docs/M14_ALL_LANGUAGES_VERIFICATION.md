# M14 — все языки / 2.2.1-build72

Дата: 2026-10-02. База — текущий main/stable 2.2.0-build71 (`0be43fb`).
Старая WIP не сливалась. Все шесть пакетов добавлены вместе; это обычное
обновление того же приложения, без beta.

## Что изменено

Модуль localization содержит **579 сообщений в восьми полных пакетах**.
Добавлены Belarusian (Беларуская), French (Français), German (Deutsch),
Kazakh (Қазақша), Spanish (Español), Ukrainian (Українська); English/Russian
сохранены. Auto первый и по умолчанию, остальные — по английскому алфавиту.
Язык выбирается из системного списка, неподдерживаемые локали получают English.

Переведены целые сообщения экранов, доступности, авторизации, коллекций,
качества, кэша, скинов, обновлятора, доната, клипов, уведомлений и сайдбара.
Согласованы разные значения лайка, локального избранного и запрета рекомендаций.
Переводы сохраняют ограничения качества, область удаления файлов и плейлистов,
а также правило загрузки только понравившихся треков.
[Термины и добавление пакета](LANGUAGE_TRANSLATIONS.md).

Четыре команды запрета/возобновления рекомендаций трека и исполнителя стали
отдельными полными фразами: прежняя вставка существительного в общий шаблон
давала неправильные падежи и артикли. Остальные параметры непрозрачны.
Метаданные, пользовательские имена, файлы, профили, алгоритмы API и плеера
не переписываются. Русский счётчик также получил правильные формы числительных.

MessagePatterns генерируется из всех пакетов и распознаёт ранее показанные
статусы при следующей смене языка, включая локальные числительные, обёртку
волны, автоматический повтор и неподтверждённое редактирование. Неоднозначные
короткие совпадения не угадываются. Генератор проверяет полноту, число/индексы
параметров, формат счётчика, plural и пробелы у составных сообщений.
