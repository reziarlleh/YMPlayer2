# Значки для руководства

27 SVG сохраняют геометрию Material Icons, используемых в
`designsystem/.../skin/PrismIcons.kt` стабильной сборки 2.1.0-build64.
Источник — AndroidX Compose Material Icons **1.7.8** (та же версия в
`gradle/libs.versions.toml`):

- [material-icons-core-android, исходники](https://dl.google.com/dl/android/maven2/androidx/compose/material/material-icons-core-android/1.7.8/material-icons-core-android-1.7.8-sources.jar)
- [material-icons-extended-android, исходники](https://dl.google.com/dl/android/maven2/androidx/compose/material/material-icons-extended-android/1.7.8/material-icons-extended-android-1.7.8-sources.jar)

Изменение для документации: экспорт Kotlin vector path в SVG и нейтральная
тёмная подложка 40×40 для читаемости на светлом и тёмном GitHub.
Форма значков не перерисовывалась. Стрелка «Назад» и очередь используют
вариант AutoMirrored, показанный для русской раскладки слева направо.

Транспортные значки на снимке со скином могут отличаться: скин вправе заменить
поддерживаемый рисунок, но не действие кнопки.
