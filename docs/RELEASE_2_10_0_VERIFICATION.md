# Проверки YMPlayer2 2.10.0-build162

Владелец принял подписанный Build 162 для стабильного выпуска. Для публикации используется тот же APK для Android 6.0 и новее.

- Android Auto проверен в Desktop Head Unit. Сценарии каталога, звуковой дорожки клипов, команд медиасессии и предыдущих клиентов описаны в [отчёте цикла](ANDROID_AUTO_2_10_0.md). Проверки физической магнитолы в отчёте отсутствуют.
- В Build 162 прошли 196 JVM-тестов и восемь инструментальных сценариев на Android 15. Проверены выделение нескольких страниц, диапазона и отдельного трека, отмена внутри альбома, очередь, раздельный поиск и локальная медиатека. Сетевые сценарии использовали тестовые ответы Яндекс Музыки.
- Подписанный Build 162 установлен поверх 161 и запущен на Android 15. Package name dev.petrov.ymplayer2, прежний сертификат и minSdk 23 сверены. [Хеш опубликованного APK](../releases/2.10.0-build162/SHA256.txt).
