# M12.5 — build49, резервные APK и обновление 48→49

Дата: 2026-09-28 UTC / 2026-09-29 местное время. Опубликован подписанный
[`2.0.0beta-build49`](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.0.0beta-build49),
`applicationId=dev.petrov.ymplayer2`, `versionCode=49`. Тег содержит APK,
необходимый для закреплённых CDN-адресов. APK выпущен из исходников с
ограниченным окном `PlaybackState.queue` и выбором новейшего валидного
манифеста из трёх узлов.

## Проверено

- `:core:test`, `:app:lintDebug`, 13 сценариев `LocalPlaybackTest` и пять
  сценариев `UpdateClientTest` прошли на Android 15. CI текущего до выпуска
  коммита завершился успешно. Release-сборка прошла `assembleRelease` и
  `lintVitalRelease`; скрипт проверил пакет, номер, отсутствие debug-флага
  и подпись APK. SHA-256 сертификата подписи совпал с build48:
  `fbc7f884d76568e5b5f7be16e83b4a39f1fedad334ebd0be7fba7aa0bea406ec`.
- Локальный APK и скачанные с GitHub Releases, закреплённого jsDelivr и Gcore
  файлы имеют размер `4 721 930` байт и одинаковый SHA-256
  `1880a913785a171b457c9ebc23d72c966daaddeb547a39dd72ec985604bd2de6`.
  [Результаты](qa/m12-5/source-hashes.txt). Манифест GitHub `main` и jsDelivr
  `@main` показывали build49; Gcore `@main` в тот же момент ещё показывал
  build48. Такая рассинхронизация является реальным входом для новой логики
  выбора максимальной валидной версии, но сама по себе не доказывает, какой
  ответ выбрал установленный клиент.
- На эмуляторе с установленным build48 ручная проверка в приложении показала
  build49 и опубликованные заметки. Кнопка загрузки открыла
  [системное подтверждение обновления](qa/m12-5/installer-build49.png).
  После установки PackageManager показал build49 и прежний
  `firstInstallTime=2026-09-09 07:09:25`:
  [пакет](qa/m12-5/after-upgrade-package.txt). Приложение открылось:
  [экран](qa/m12-5/after-upgrade.png). В проверенном фрагменте error-logcat
  не было `AndroidRuntime`, `FATAL EXCEPTION` или SQLite-ошибок приложения.

В тестовом профиле перед этим обновлением не было пользовательской коллекции,
поэтому сохранение её данных именно в переходе 48→49 не доказано. Более ранняя
проверка данных 40→41→42 находится в [M12.2](M12_2_VERIFICATION.md).
Установку 48→49 инициировал **клиент build48**, поэтому она также не проверяет
новую схему выбора манифеста в установленном build49; пока её доказывают пять
инструментальных тестов и совпадение опубликованных APK. Сквозной тест
клиента build49 против следующего релиза, резервный путь в сети владельца,
миграции и полная выпускная регрессия остаются открыты. M12 не завершён.

Текст списка источников на экране build49 всё ещё называл только GitHub и
jsDelivr; в исходниках после выпуска добавлено упоминание Gcore. Это изменение
ещё не входит в опубликованный APK.
