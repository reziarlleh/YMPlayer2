# M11.7 — переход локального аудио без обхода полного каталога

Дата: 2026-09-29. Изменение исходников после опубликованного build49;
нового подписанного APK ещё нет.

При естественном переходе Media3 к следующему локальному треку
`AndroidPlayback` теперь запрашивает в SQLite текущую позицию, до 29
видимых строк и до 29 доступных соседних файлов. Он больше не вызывает
`defaultQueue()` для этого перехода. Запрос учитывает выбранный источник,
сохраняет порядок `title_key,id` и не включает недоступные файлы в Media3.
Позиции экранной очереди остаются абсолютными. Ответ старого запроса
отбрасывается после смены профиля, источника, ревизии индекса или трека.

На Android 15 прошли 13 `LocalPlaybackTest` и 3 `LocalIndexMigrationTest`:
дальний выбор, автоматический переход, ограничение Media3, фильтр USB,
недоступные ссылки и миграция SQLite v1→v2; 0 ошибок
([XML](qa/m11-7/local-android15.xml)). Ещё 17 сценариев
`CollectionsPlaybackTest`, `WaveQueueModeTest`, `SystemBrowserTest` и
`StorageRecoveryTest` прошли без ошибок
([XML](qa/m11-7/regressions-android15.xml)). `core:test`, сборка debug и
`app:lintDebug` завершились без ошибок.

Это промежуточный результат M11. `SafLibrary.state.tracks` всё ещё держит
полный каталог; первоначальная загрузка, дальний выбор, ручные изменения
очереди и переход за краем окна пока его читают. Shuffle и повтор всей
очереди по-прежнему передают Media3 полный список. Единый индекс с
Яндекс-каталогом и проверка большой коллекции открыты. Проверка на K4811,
физическом USB и HyperOS не проводилась.
