## Подготовка English build70 — история

M14 / 2.2.0 возобновлён 2026-10-02 заново от последнего stable
2.1.5-build69, HEAD `00e624e`. Свежая ветка `codex/2.2.0-localization-restart`
не сливается с прежней WIP. В ней сохраняются все исправления 2.1.2–2.1.5:
пульт, общий заголовок/«О приложении», донат и раздельные экраны офлайн-кэша.
Первая цель — English, Auto/Russian и расширяемые переводы, проверки Android/TV,
подписанная beta для владельца. Старый каталог английских формулировок использован
только как справочник текста; исходники и зависимости пересобраны на базе build69.
Код плеера, кэша и API из старой ветки не переносится. Реализован отдельный
модуль localization: 575 сообщений English/Russian, сохраняемый выбор языка
и смена текста без пересоздания проигрывателя. 17 разных сценариев прошли
на каждом проектном эмуляторе Android 15/TV29; signed70 установлен поверх69,
English/Russian сохраняются после холодного запуска.
[Beta70 опубликована](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.2.0beta-build70):
GitHub/jsDelivr/Gcore APK совпали по размеру/SHA-256, beta-манифест70 опубликован.
Stable69 остаётся стабильным. Первая цель завершена; приёмка English владельцем
открыта, расширение языков начинается после неё.
[Результаты M14](M14_VERIFICATION.md) · [Добавление языка](LANGUAGE_TRANSLATIONS.md).
Остальные языки и английская инструкция идут после проверки English.
Google Play отложен до обсуждения; 4PDA ждёт прав на шапку.

Прежняя попытка от build65 сохранена в локальной ветке
`codex/2.2.0-localization-wip` как историческая заготовка. Не сливать её в main,
не восстанавливать файлы shell/designsystem/app из неё целиком.

## Первая цель: английский и расширяемые переводы

1. Сверить все тексты экранов, доступности, native-клипов, уведомлений и ошибок.
2. Вынести контекстные переводы в отдельный модуль и каталог; исходные данные
   музыки, имена пользователей, плейлистов и импортированных скинов не переводить.
3. Добавить сохраняемый общий для устройства выбор языка. Auto первым и по
   умолчанию, затем English (English), Russian (Русский). Auto учитывает язык
   системы; при отсутствии перевода используется English. Русская система
   продолжает показывать русский интерфейс.
4. Проверить переключение без потери профиля/настроек/воспроизведения, возврат
   к Auto, перезапуск, touch/D-pad, клипы, уведомления и длинные тексты.
5. Выпустить подписанный 2.2.0-build71 без beta в основном канале обновлений.
   Уточнение владельца 2026-10-02 заменяет первоначальный план beta.
   Остальные языки не объявлять готовыми до появления переводов.

Первоначальная цель завершена после проверок и публикации build70; обычное
обновление исправляется stable71 по новому уточнению владельца. Самостоятельная
проверка владельцем — отдельная отметка, после которой расширяем набор языков.

## Полный набор после проверки английского

Порядок по английским названиям, Auto всегда первым:

| --- | --- |
| system | Auto — system language / Авто — как в системе |
| be | Belarusian (Беларуская) |
| en | English (English) |
| fr | French (Français) |
| de | German (Deutsch) |
| kk | Kazakh (Қазақша) |
| ru | Russian (Русский) |
| es | Spanish (Español) |
| uk | Ukrainian (Українська) |

Переводить целые сообщения с учётом назначения кнопки и контекста. Использовать
привычную терминологию музыкальных приложений; одинаковое действие называть
одинаково. Параметры, длительность и пользовательские названия сохранять.
Проверять числа/множественные формы, читаемость и переполнение.
