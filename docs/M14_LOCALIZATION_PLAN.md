# M14 — мультиязычный интерфейс / 2.2.0

Начат по запросу владельца 2026-10-01 на stable 2.1.1-build65.
Актуальный выпуск указан в [PROJECT_STATUS](PROJECT_STATUS.md).
Приостановлен по прямому указанию владельца до исправления проблем 2.1.
Следующая работа — исправления 2.1 после получения описания проблем.

## Первая цель: английский и расширяемые переводы

1. Сверить все тексты экранов, доступности, native-клипов, уведомлений и ошибок.
2. Вынести контекстные переводы в отдельный модуль и каталог; исходные данные
   музыки, имена пользователей, плейлистов и импортированных скинов не переводить.
3. Добавить сохраняемый общий для устройства выбор языка. Auto первым и по
   умолчанию, затем English (English), Russian (Русский). Auto учитывает язык
   системы; при отсутствии перевода используется English. Русская система
   продолжает показывать русский интерфейс.
4. Проверить переключение без потери профиля/настроек/воспроизведения, возврат
   к Auto, перезапуск, touch/D-pad, клипы, уведомления и длинные тексты.
5. Выпустить подписанный 2.2.0beta со следующим сквозным Build для проверки
   владельцем. Остальные языки не объявлять готовыми до появления переводов.

Цель завершена после фактических проверок и публикации beta; самостоятельная
проверка владельцем — отдельная отметка, после которой расширяем набор языков.

## Полный набор после проверки английского

Порядок по английским названиям, Auto всегда первым:

| Код | Название в списке |
| --- | --- |
| system | Auto — system language / Авто — как в системе |
| be | Belarusian (Беларуская) |
| en | English (English) |
| fr | French (Français) |
| de | German (Deutsch) |
| kk | Kazakh (Қазақша) |
| ru | Russian (Русский) |
| es | Spanish (Español) |
| uk | Ukrainian (Українська) |

Переводить целые сообщения с учётом назначения кнопки и контекста. Использовать
привычную терминологию музыкальных приложений; одинаковое действие называть
одинаково. Параметры, длительность и пользовательские названия сохранять.
Проверять числа/множественные формы, читаемость и переполнение.

Незавершённые изменения сохранены отдельно в локальной ветке
`codex/2.2.0-localization-wip`: модуль переводов, английский/русский каталог,
выбор Auto/English/Russian и подключение текстов интерфейса. Первая сборка
не прошла компиляцию shell; проверка переключения языка ещё не выполнена.
При возобновлении сначала исправить ошибки компиляции и сверить изменения
с последующими исправлениями 2.1. Это заготовка, а не готовая реализация.

APK 2.2 не выпущен, новый Build не выделен. Основная ветка содержит код 2.1
и этот план; изменения локализации не входят в исправления 2.1.
Остальные языки, английская инструкция и Google Play остаются в порядке выше.
