# 4PDA — выпуск2.7.0-build137 и история совместимости

13 ноября2026 по прямому поручению владельца после GitHub-релиза опубликовано
одно авторское [сообщение №109 отreziarlleh](https://4pda.to/forum/index.php?showtopic=1127108&view=findpost&p=145991001),
прикреплён APK36539326. Шапка —2.7.0/13.11.2026, Android6.0+, APK36539381.
[Обратное чтение, вложения и полные загрузки](qa/release270/forum.json).

## Оформление и свежая база

Применён штатный Релизер: «Новая версия», точная версия2.7.0-build137,
краткое поле Android6.0 и выше, полный накопленный состав2.7.0 из семи пунктов
под спойлером. Вне него — короткий текст в стиле авторского№94, ссылки GitHub/
резервной загрузки/инструкции, установка поверх и пояснение о том же APK137.
Повторного сообщения не создавалось.

Перед правкой перечитаны [правила программ](https://4pda.to/forum/index.php?act=announce&f=212&st=250)
(редакция23.10.2026) и [кураторов/топикстартеров](https://4pda.to/forum/index.php?act=announce&f=212&st=368)
(04.10.2025). Прямые HTTP-запросы вернули200. Стандартные поля Мастера сохранены:
основная версия2.7.0, полный Build в загрузке, новая дата для новой стабильной версии.

Исходная серверная шапка имела SHA256
`80ba2b25fdd3f254e7abb02617effcdaf628e349f62205bdf703548a2d6aacdb`.
После публикации Релизер с задержкой обновил верхнюю версию/дату и добавил
строку-ссылку на№109. Повторный GET выявил изменение до сохранения. Старый
патч не сохранялся: подтверждено, что разница содержит именно эти три
автоматические правки, затем патч перенесён на новую базу
`295a915d371e7b9c74de853497e3fceda7a8fb3b8666c23f2dfe5cc2a6a03ae5`.
Непосредственно перед POST ещё один GET подтвердил новую базу. Сохранённая
форма точно совпала с проверенным целевым BBCode:
`981a3679f418c3234d40faa6a9346eb148cf4ed37c7fe92d4882debdbdc48c23`.

Описание владельца и шесть снимков сохранены. В сравнении версий добавлен
только пункт2.7 и расширено название спойлера до2.0–2.7. Иконка осталась вне
спойлера; удалённые прежде копии скриншотов/формулировки не возвращались.

## Android6+,9+ и10+

По дополнительному прямому указанию владельца в актуальном поле требований
стоит **Android6.0 и выше**. Старые пакеты разделены внутри «Прошлых версий»:

- **Android9+**:13 строк-ссылок на сообщения с APK, от2.6.6-build132/№106
  до2.4.0beta-build80/№10. Полные старые блоки APK/GitHub/зеркал не возвращались.
- **Android10+**:2.3.4-build79/№6 и2.3.3-build78/№4, затем сохранённые блоки
  2.1.0-build64,2.0.2-build62 и1.1.0-build114. Их прежние файлы и ссылки сохранены.

Граница сверена по манифестам настоящих архивных APK через aapt, включая1.x:
minSDK28 начиная с80, minSDK29 у перечисленных более ранних пакетов.
[SDK/Build/контрольные суммы](qa/release270/historical-sdk.json).
История не сгруппирована по предположению о номере версии.
