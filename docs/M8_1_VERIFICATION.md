# M8.1 — системный MediaBrowser

Дата: 2026-09-24. Первый шаг M8, перенос F20 по [ADR-019](DECISIONS/ADR-019-system-browser.md).

Вместо прежней только MediaSession служба публикует Media3 MediaLibrarySession
и совместимый системный MediaBrowser. Дерево содержит ровно два источника 1.x:
«Моя волна» (`ymp_my_wave`) и скачанные «Мне нравится» (`ymp_liked_cache`).
Выбор не запускает аудио; Play передаёт команду существующим механизмам волны
или офлайн-кэша текущего профиля. Неизвестный ID и переданный внешним клиентом
URI не добавляют файл в очередь. Внешний клиент видит тот же transport и
foreground-уведомление, что и интерфейс приложения.

  `:app:lintDebug` успешны. Lint: 0 ошибок, 22 предупреждения.

  настоящего локального аудио и режимов волны. Корень, два ID, пагинация,
  чтение элемента, отказ от постороннего URI и подключение старого
  MediaBrowser проверены на обоих. Команды выбора пустого офлайн-кэша через

Протоколы native-тестов: [Android 15](../qa/m8-1/android-15.xml),

Артефакт и контрольные файлы: [GitHub prerelease](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.0.0beta-build22).

Реальный CWG, физические медиакнопки, переключение аудиофокуса и сценарии
загрузки/переподключения на головном устройстве этим тестом не подтверждены.
Для них нужен отдельный проход на целевом устройстве с разрешения владельца.
Персональная офлайн-коллекция и волна в аккаунте владельца требуют проверки
именно на его данных; native-тесты использовали контролируемые фикстуры.
