# M10.5 — геометрия и фон SideBar

Дата: 2026-09-28. Подписанная beta `2.0.0beta-build43` (`versionCode=43`).

По замечанию владельца изменён только слой оформления встроенного SideBar.
У свободного края панели теперь срезы с равными горизонтальной и вертикальной
сторонами, то есть под 45°. Такая геометрия сохраняет место для кнопок в
портрете и альбомной ориентации. Внутренние отступы увеличены с 10/12 dp до
18/22 dp по горизонтали/вертикали. Полупрозрачный фон слегка затемнён:
`ARGB(190, 12, 16, 23)` → `ARGB(205, 8, 11, 17)`. Круглая форма кнопок,
их команды, настройки и невидимые зоны жеста не менялись.

Проверено на Android 15: `:app:assembleDebug`, `:app:lintDebug` и два
инструментальных сценария `SideBarOverlayTest` прошли без ошибок и пропусков.
Визуально просмотрены правая и нижняя панели в debug, а затем правая панель
подписанного APK в [портрете](qa/sidebar43-open-phone.png) и
[альбомной ориентации](qa/sidebar43-open-landscape.png): контур замкнут,
кнопки остаются внутри него и не касаются скосов. Подписанный build43
установлен поверх build42 на эмуляторе, `firstInstallTime` сохранился:
`2026-09-09 07:09:25`. SHA-256 APK:
`8bc6cbe50562559334ac9f32b2d1ed6b70bd08fe61b74649d3e5f6e9aec03566`.

Внешний вид и жесты на физической K4811 остаются за приёмкой владельца;
визуальная проверка эмулятора их не подтверждает.
