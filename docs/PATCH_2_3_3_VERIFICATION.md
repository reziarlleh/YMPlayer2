## Приближение Galaxy A14

Отдельный AVD `YM2_A14_API35`/emulator-5558 создан на установленном AOSP API35
x86_64, экран1080×2408,4GiB RAM,256MiB VM heap,4vCPU, без аппаратной клавиатуры.
Разрешение соответствует [официальной спецификации Samsung](https://www.samsung.com/ph/business/smartphones/galaxy-a/galaxy-a14-black-mist-128gb-sm-a145fzkvphl/).
4GB — выбранный тестовый вариант, RAM/точная модель/настройки автора неизвестны.
Плотности420/480, шрифт100/130/200%, портрет/альбом проверены отдельно.
Это12 сочетаний, а не12 разных аппаратных моделей. Android15 совпадает с
отчётом, Samsung/One UI/ARM и Samsung Keyboard не воспроизводятся AOSP.

На настоящем подписанном stable77 все12 случаев касания поля и ввода прошли,
IME видима, PID до/после совпадает, crash buffer пуст.
[Матрица](qa/forum-2026-10-04/a14-matrix77.json).
Основной проектный API35 ранее прошёл три касания/ввода.
На AVD нет личного аккаунта автора; путь с авторизованным fixture и
локальным аудио прошёл отдельно native тестом на всех трёх эмуляторах.

## Разобранные гипотезы

- IME/Compose: первичные команды InputConnection, composing text,
  изменение extracted/cursor state могут отличаться между клавиатурами.
  Поиск использует обычный String OutlinedTextField без VisualTransformation
  или собственного OffsetMapping. Старый [отчёт Google](https://issuetracker.google.com/issues/322835187)
  относится к mapping/readOnly в Compose1.6, поэтому не доказывает причину здесь
  (проект использует Foundation1.12.0). Не переносить чужой workaround вслепую.
- Resize/фокус: поле внутри LazyColumn, imePadding и скрытие панели в коротком
  окне. Матрица включает шрифт/поворот и настоящий показ IME; вылета нет.
- Нехватка памяти/системное завершение: журнал событий не отличает эти
  причины от Java crash. Новая диагностика добавляет причины Android на API30+.
- Обновление зависимостей: просмотрен [официальный changelog Foundation](https://developer.android.com/jetpack/androidx/releases/compose-foundation).
  Совпадающее подтверждённое исправление не установлено, BOM не изменён.

Samsung Keyboard нельзя считать причиной только по марке телефона.
Ни одна гипотеза пока не подтверждена для B-007.
