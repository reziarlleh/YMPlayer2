# M12.1 — собственные обновления 2.x

Дата: 2026-09-28. Выпуск: `2.0.0beta-build40`.

Репозиторий YMPlayer2 стал публичным после проверки отслеживаемых файлов и
истории на ключи подписи, OAuth-токены и личные данные. Исходные ключи и
локальная конфигурация находятся вне Git. Условия повторного использования
исходного кода отдельной лицензией пока не определены.

По [ADR-027](DECISIONS/ADR-027-independent-updater.md) новая версия переносит
рабочую схему 1.x: GitHub → jsDelivr для манифеста и APK, проверку размера и
SHA-256, выбор по `versionCode`, проверку 2.x-пакета и текущей подписи, затем
системный установщик Android. Отдельный модуль `updater/android` не знает об
аудио, клипах или профилях. При запуске по умолчанию выполняется проверка не
чаще раза в сутки, есть ручная проверка и выключатель в настройках. Новая
версия предлагается пользователю; загрузка и установка требуют его действия.

Перед выпуском пройдены `:app:assembleDebug`, `:app:lintDebug`, три
инструментальных сценария модуля обновлений (резервный манифест, отклонение
чужого пакета/HTTP/канала и повреждённого APK) и четыре сценария экрана
навигации/настроек на Android 15. Первый объединённый запуск инструментальных
задач был некорректен: общий фильтр класса теста был применён также к модулю
обновлений. Повторные отдельные запуски прошли.

Подписанный release-скриптом APK `versionCode=40`, пакет
`dev.petrov.ymplayer2`, неотладочный; подпись проверена. SHA-256:
`003b16d7a27ad7e25b9f469ca941a4162a94208629a3f063278a2e8880848409`.
Он установлен поверх build39 на Android 15 без сброса данных:
`firstInstallTime=2026-09-09 07:09:25` сохранился. Приложение запущено.
Проверка опубликованных GitHub/jsDelivr URL фиксируется после выпуска.

Открыто до стабильного 2.0.0: сквозная установка новой версии именно из UI на
физическом устройстве, доступность jsDelivr из сети владельца, миграции данных,
полная регрессия и оставшиеся пункты M8–M11. Android не допускает тихую
установку APK обычным приложением: пользователь подтверждает системный экран.
