# 2.4.0beta — Android 9 / API 28

Утверждено владельцем 2026-10-05. База — main / stable 2.3.4-build79,
после [оценки совместимости](API_28_FEASIBILITY.md). Одна последовательная
линия разработки, без параллельных исправлений 2.3.

## Объём и порядок

1. Снизить minSdk 11 Android-модулей до 28, сохранив target36/compile37.
2. Адаптировать foreground офлайн-синхронизации, экспорт диагностики и
   освобождение MediaMetadataRetriever; сохранить пути API29+.
3. Проверить lint всех модулей и целевые runtime-сценарии на API28, TV29 и API35.
   Замечания B-009 устранить точечно, если они мешают полной проверке.
4. Выделить следующий сквозной Build, собрать APK прежним ключом, проверить
   пакет/минимум/подпись и signed установку поверх79 на прежних эмуляторах.
5. Опубликовать GitHub **prerelease**, ручную ссылку и отчёт. GitHub latest,
   `update/manifest.json` и `update/stable.json` сохраняют stable79/min29.

## Ограничение распространения

2.4.0beta не публикуется в манифестах автоматического обновления до явного
подтверждения стабильной работы на прежних устройствах владельцем/пользователями.
Проектные тесты и эмуляторы не заменяют это подтверждение. Beta сохраняет
applicationId и сертификат2.x; установка поверх2.3 сохраняет данные.
Клиент beta продолжает слушать **stable** feed, чтобы после отдельного решения
получить стабильный выпуск с более высоким Build. Отдельного beta feed нет.
Возврат на79 после установки beta с более высоким versionCode обычным
installer невозможен; удаление приложения удаляет его приватные данные.
