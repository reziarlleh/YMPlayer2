# M11.2 — дисковый индекс локального/USB-каталога

Дата: 2026-09-28. Выпуск: `2.0.0beta-build44`.

## Реализовано

- SQLite `local-catalog.db` хранит корни и метаданные; прежний JSON импортируется
  однократно и атомарно с маркером завершения. ID, SAF URI и обложки сохраняются.
- Завершённый обход заменяет индекс транзакцией. При недоступном USB старые
  строки остаются с `available=false`; после перезапуска доступность проверяется
  заново. Оригинальные аудиофайлы не копируются.
- Экран локальной медиатеки и поиска получает из индекса по 80 строк за запрос,
  включая фильтры, сортировку, группировки и детали. «Показать ещё» читает
  очередную порцию с `OFFSET`, а не перечитывает уже показанный префикс.
- Полный снимок пока остаётся в памяти для очереди, плейлистов и
  воспроизведения. Яндекс-каталог остаётся на своей странице. Это часть M11,
  не завершение всего F16; граница зафиксирована в [ADR-028](DECISIONS/ADR-028-local-disk-catalog.md).
