Сверено12 октября2026. Опубликован **[2.5.5-build104](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.5.5-build104)**,
ручной масштаб интерфейса. GitHub latest и оба stable feeds переведены на104.

## Текущий результат

Текущая работа — [2.6.0](PLAN_2_6.md): значки клипов, STOP на TV,
перенос кэша и экспорт MP3 с шаблоном имён. Опубликованная версия пока104;
реализация и проверки нового этапа не объявляются готовыми заранее.
Кандидат2.6.0-build105 подписан, но не опубликован: финальная проверка API28
потребовала явных MIME. Добавлены export recovery/account guard; проверки
продолжаются, следующий подписанный APK получит новый сквозной Build.

- Настройки → Масштаб интерфейса:50–200%, шаг10%, живой предпросмотр,
  сохранение независимо от темы/профиля/скина и сброс100. Настройка пультом.
- Редактор остаётся неподвижным при drag. Главный плеер удерживает основные
  кнопки в доступном окне без прокрутки; размер клипа/TextureView не меняется,
  масштабируются только кнопки и текст видеоплеера при открытии.
- API28/TV29/API35:11/11 native на каждой платформе. Матрица6 размеров
  от800×480 до1920×1080 и вертикального720×1280 прошла на API35;
  в каждом случае50/100/150/200%. Core125, lint0 errors/66 warnings,
  678 сообщений/8 языков. Первоначальные отказы и исправления сохранены.
- Настройка не меняет аудиодекодер, трек или очередь; позиция продолжается.
  Клипы проверены настоящим ClipActivity с локальными фикстурами.
- Signed104 собран прежним ключом/package/minSdk28;102→104/API28 установлен
  без очистки. Сохранены Settings, английский UI и локальный трек;130% и маршрут
  пережили завершение процесса, reset100 работает.
- GitHub latest/default main/README и оба feeds сверены. Скачанные GitHub и
  основной резервный APK совпали по SHA256. Основной CDN отдаёт оба feeds104;
  дополнительный Gcore stable ещё отдавал102 в HTTP-срезе00:27/12 октября

- Основа main/stable102. Код отдельного эксперимента приборки не перенесён,

## Возможности и завершённые этапы

- 2.0: музыка local/USB/Яндекс, профили, волна/рекомендации, реакции,
  плейлисты, офлайн «Мне нравится», клипы, MediaSession, K4811 SideBar, updater.
- 2.1: скины/руководство, TV/клипы, выключатель кэша, «О приложении»,
  единый заголовок и отдельные настройки кэша.
- 2.2: Auto и восемь языков, смена языка без остановки музыки.
- 2.3: история профиля, недавно добавленные local/USB, массовый выбор,
  сохраняемая диагностика падений и исправленный рекурсивный фокус79.
- 2.4: настройки/источники волн, режимы списков, продолжение волной,
  переключатель источника и API28.
- 2.5: эфирное Радио между Поиском и Клипами, коллекция/каталоги/карточки,
  общий AudioService/CWG, сохранение Music/Radio/Clip, сетевой grace/Retry.
  В98 исправлены запуск/геометрия клипов и задержки офлайна/первого потока.

## Остаточные наблюдения

- B-027: несогласованные ◀/▶▶ в клипах; открыт после104, исправление ещё
  не выполнялось. [Сверка автовосстановления и значков](AUTO_RESUME_2_5_5_REVIEW.md).
- USB конкретного ГУ и однообразие волны у одного пользователя — проверить
  по следующему отзыву, не требовать ADB/физического доступа для продолжения.
- D-003: исследование приборки/ручной beta99 приостановлено владельцем;
  дальнейшие экспериментальные изменения не выполняются.
- D-001: динамический CDN может запаздывать; при выпуске фиксировать HTTP-срез.
  D-002: причина проверки APK Android/HyperOS не доказана, подпись сохраняется.
- B-018: геометрия клипов проверена эмулятором; физическая приёмка HyperOS
  остаётся дополнительным результатом, не новой обязанностью владельца.
- K4811/CWG/личная FM-коллекция — физические отзывы учитывать отдельно.
- 4PDA: ждать прав на шапку, затем править её по свежей форме модератора;
  автоматических новых сообщений не создавать.
