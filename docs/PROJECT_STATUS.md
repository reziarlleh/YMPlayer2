# Текущий статус YMPlayer 2

Сверено 14 октября 2026. **2.6.2-build113** проверен на физическом KIVI 4K
Android TV14/API34; публикация и сверка каналов обновления завершаются.
Одна основная main, самостоятельное приложение dev.petrov.ymplayer2,
Android9/API28 и новее; 1.x для работы не требуется.

## Результат 2.6.2

На настоящей системной карточке Kivi проверены «Открыть» и «Остановить»:
музыка/Моя волна и радио, повторный запуск после остановки, возврат из медиатеки,
нажатия по экрану и DPAD/Center. Звук прекращается, позиция не растёт,
карточка не возвращается спустя7–9 секунд. Open возвращает в активный player/radio
без изменения Play/Pause. firstInstallTime сохранён, данные не очищались,
разрешения не выдавались. [Физические результаты](TV_NOTIFICATION_2_6_2_VERIFICATION.md).

Исправлены видимость системных NotificationListenerService для проверки доверия
Media3 и параметры sessionActivity для запуска из фоновой системной службы
Android14. Стандартный Media3 provider, metadata и транспортные команды сохранены.
Новых пользовательских строк нет; RU/EN инструкции сверены.

Build109 **не исправил** обе кнопки: утверждение об исправлении отозвано,
неудачная попытка сохранена в технической истории. 110–112 — локальные кандидаты,
не опубликованы. Эмуляторные проверки старой попытки не заменяют результат Kivi.
[План](PLAN_2_6_2.md) · [Ошибочные решения](LESSONS_LEARNED.md).

## Основа 2.6.1

Моя волна: raw cursor, recovery и история по профилю/UID. Продолжение волной
сохраняет естественный конец списка; Prev/Next соответствуют доступным трекам.
Кэш нового like, удаление unlike/block и отложенные операции; MP3 экспорт
128/192/256/320 без Auto. Диагностика различает network/HTTP/server/format/player.
[Проверки и ограничения](PATCH_2_6_1_VERIFICATION.md).

2.6.0: выбор File/SAF/USB папки кэша, проверка места/копии/перенос всех профилей,
MP3 экспорт с тегами и редактируемым шаблоном. [История](FILE_TRANSFERS_2_6_VERIFICATION.md).
