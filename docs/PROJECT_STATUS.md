# Текущий статус YMPlayer 2

Сверено 13 октября 2026. Подготовлен стабильный **2.6.0-build106**;
публикация и HTTP-сверка завершаются. Одна линия main, публичный
reziarlleh/YMPlayer2, dev.petrov.ymplayer2, Android 9/API28 и новее.
2.x — самостоятельное приложение, версия1.x не требуется.

## Результат 2.6

- Симметричные ⏮/⏭ в клипах. Системная STOP на TV прекращает музыку/радио
  и удаляет карточку; повторный Play работает, радиоповторы и on-air polling остановлены.
- Настройки офлайн-кэша: выбор папки/USB, проверка места, перенос всех профилей,
  аудио/обложек/метаданных/контрольных сумм с проверкой копии до удаления исходного.
  Отмена/отказ/перезапуск сохраняют активное хранилище. Возврат во внутреннюю память.
- Экспорт MP3 офлайна, Яндекс-альбомов/плейлистов; все страницы и порядок списка.
  MP3 packet copy, преобразование других поддержанных источников с тегами,
  отмена и восстановление собственных временных файлов. Чужие файлы не перезаписываются.
- Сохраняемый шаблон имён, пример и (?) справка;46 новых сообщений,724 всего/8 языков.
  Сетевой sync не блокирует чтение уже скачанного трека.
- Core128 JVM, release lint0 errors/67 warnings. Native API28/TV29 —21/21,
  API35 —40/40: перенос/отмена/отказы/recovery/account/HTTP, decode MP3/AAC,
  язык/шаблон/пульт/STOP и прежний офлайн/клипы. Это эмуляторы, не физические USB/ГУ.
- Signed104→106/API28 без очистки: английский UI, настройки, локальный трек,
  маршрут после force-stop; новые cache settings/About открываются. После масштаб100%,
  до обновления значение не наблюдалось — его сохранение этим прогоном не доказано.
- Прежние package/min28/cert. Кандидат105 не опубликован, номер не переиспользован.
  Параллельная beta приборки/утилита не изменялись.
