# Текущий статус YMPlayer 2

Сверено 13 октября 2026. Опубликован стабильный **[2.6.1-build107](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.6.1-build107)**.
GitHub Latest и оба update feeds107; GitHub/резервный APK совпали по SHA256. Одна линия main, публичный reziarlleh/YMPlayer2,
dev.petrov.ymplayer2, Android9/API28 и новее. 2.x — самостоятельное приложение,
версия1.x не требуется. [Результаты и границы](PATCH_2_6_1_VERIFICATION.md).

## Результат 2.6.1

- Моя волна: курсор из raw ответа, восстановление повторной выдачи и история
  по профилю/аккаунту; проверен переход за первой десяткой на controlled API.
- Продолжение волной сохраняет естественный конец списка при source refresh.
  Prev/Next в UI и MediaSession доступны только при соответствующем треке.
- Автоматический кэш нового track like; unlike/block удаляют файл и отменяют
  загрузку. Отложенные server actions/downloads переживают перезапуск, разделены
  по профилю/UID. Pending unlike не возвращается через manual sync.
- Экспорт MP3: 128/192/256/320, сохраняемое качество без Auto; фактические
  файлы проверены. 735 сообщений во всех восьми языках, обе инструкции актуальны.
- Диагностика: операция, категория, HTTP/network/Media3, счётчики wave recovery.
  Журнал ограничен и не содержит URL/токенов/персональных ответов.
- 141 JVM, lint0 errors/67 warnings; API28 55/55 и TV29 28/28.
  API35 39/40: первичный replay-radio fail сохранён; отдельно1/1 и весь блок6/6
  прошли без изменения кода. Это эмуляторы; персональная/физическая приёмка отдельно.
- Прежние package/min28/cert, cache formatv1. Beta приборки/утилита не менялись.
