# Текущий статус YMPlayer 2

Сверено 6 октября 2026 года: **[2.4.1-build84](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.4.1-build84)**,
публичный `reziarlleh/YMPlayer2`, `main`, пакет `dev.petrov.ymplayer2`, minSdk28.
GitHub latest и оба stable feeds указывают на84. Прежние beta80–82 остаются
историческими prerelease.2.x — самостоятельное приложение;1.x не требуется.

Текущая линия — **[2.5.0beta-build87](https://github.com/reziarlleh/YMPlayer2/releases/tag/v2.5.0beta-build87)** на той же `main`: полноценный
раздел эфирного Радио, опубликованный ручной beta; стабильный канал/latest остаются на84.
Проверочная beta86 сохраняется как исторический прототип. [План2.5](PLAN_2_5.md),
[проверки87](RADIO_2_5_VERIFICATION.md).

## Реализовано и опубликовано

- 2.0: локальная/USB и Яндекс-музыка, профили, волна, рекомендации, реакции,
  плейлисты, офлайн «Мне нравится», клипы, MediaSession, K4811 SideBar, updater.
- 2.1: пользовательские скины и руководство, исправления TV/клипов,
  выключатель кэша, «О приложении», единый заголовок, отдельные настройки кэша.
- 2.2: Auto и восемь языков, смена языка без остановки музыки.
- 2.3: история профиля, недавно добавленные local/USB, массовый выбор,
  сохраняемая диагностика падений; B-007 исправлен в79.
- 2.4: занятия/характер/настроение/язык волны из API текущего аккаунта,
  волны по треку/артисту/альбому/плейлисту. Взаимоисключающие repeat ALL/ONE,
  бесконечный shuffle и продолжение волной после Яндекс-списка; источник
  сохраняется при восстановлении. Кнопка источника выбирает My Wave/offline/local favorites.
  Android9/API28. [План и результат](PLAN_2_4.md).
- 2.4.1: настройки показываются только у активной «Моей волны», в том числе
  на паузе; смена источника закрывает окно. Алгоритмы плеера/updater не менялись.

Полная [карта функций](FEATURE_INVENTORY.md), [модули/перенос](MIGRATION_MAP.md),
[история версий](../CHANGELOG.md). Офлайн синхронизирует только понравившиеся
треки, не альбомы и исполнителей целиком. README содержит описание продукта.

## Проверки стабильного выпуска

Для patch84: 101 JVM, debug/release lint без ошибок, 15 целевых сценариев
на TV10/API29 и те же 15 на Android9/API28. Первичный сбой фокуса API28
не повторился отдельно и в соседних сценариях; исходные логи сохранены.
Подписанные загрузки и обновление поверх83 проверены отдельно.
[Результат и границы](PATCH_2_4_1_VERIFICATION.md).

Историческая база stable83: владелец принял беглый осмотр beta82 и разрешил
stable после регрессии.101 JVM и748 runtime-сочетаний относятся к83,
а не к новому прогону84; [отчёт83](RELEASE_2_4_0_VERIFICATION.md).
Эмуляторы не доказывают полную физическую проверку всех моделей или работу
Google Play Protect/HyperOS scanner.

## Открыто и следующий шаг

- Проверка существующего Music OAuth завершена 6 октября: экспорт владельца
  из beta86 на Android16/API36 подтверждает личный аккаунт FM и совпадение UID
  с Music/сохранённым профилем. Избранные станции и треки доступны с HTTP 200;
  оба списка пусты. Без токена/с неверным токеном коллекции отвечают 401.
  Отдельный вход для этих чтений не нужен. В87 запись избранного и воспроизведение FM
  реализованы. Эфир проверен на эмуляторах; реальная запись в аккаунт владельца
  ещё требует пользовательской приёмки. [Результат и границы](YANDEX_RADIO_AUTH_PROBE.md),
  [план2.5](PLAN_2_5.md).

- B-011 исправлен в84. D-002 остаётся наблюдением: точный текст предупреждения
  установки отсутствует, подпись/permissions/target/updater не изменились.
  [Разбор](PATCH_2_4_1_VERIFICATION.md). Patch84 не объявлен исправлением D-002.
- Раздел Радио завершён в87 по выбранному варианту1: каталог/поиск/города/жанры,
  коллекция станций, эфир/метаданные/лайк/плей/стоп. OAuth-прототип из диагностики
  удалён. 108 JVM, 50 пройденных native-проверок и один TV-only пропуск на телефоне;
  debug/release lint без ошибок. Подписанное обновление86→87 и настоящий HTTPS/HLS
  эфир проверены на API28 и TV29; [отчёт](RADIO_2_5_VERIFICATION.md).
- **B-006**: переводы отсутствующих локальных тегов, независимый отложенный шаг
  текущей линии2.5 после раздела Радио.
  Реальные названия музыки и пользовательские данные не переводить.
- Отдельный русский фильтр дополнительно к региональному не подтверждён API:
  [ADR-040](ADR_040_WAVE_SETTINGS.md). Не подменять одну настройку двумя названиями.

  Свежесть всех будущих запросов CDN не гарантируется.

  независимая работа не останавливается. B-007 закрыт по стеку и native-повтору.
