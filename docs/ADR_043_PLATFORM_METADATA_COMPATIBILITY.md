# ADR-043 — совместимые поля системных метаданных

8 октября2026. По запросу владельца выпущена ручная 2.5.2beta-build99 из текущей main.
Основание — [FMPLAY/YMPlayer на одном API28](FMPLAY_COMPARISON.md): у signed98
нет DISPLAY_* и ART. Причина исчезновения карточки на приборке пока не доказана.

## Решение

Music заполняет displayTitle=название, subtitle=исполнитель, description=альбом.
Radio сохраняет прежний TITLE=станция, ARTIST=песня · исполнитель и повторяет
их в displayTitle/subtitle; description=город, albumTitle=станция. Это сохраняет
представление CWG и не позволяет тегу альбома из потока подменить станцию.
Возобновляемый музыкальный элемент также получает displayTitle/subtitle/description.
Пустые теги остаются пустыми, названия интерфейса не подменяют реальные теги.

Media3 1.11.0 не переносит Bitmap из extras в legacy-метаданные; его
[LegacyConversions](https://github.com/androidx/media/blob/1.11.0/libraries/session/src/main/java/androidx/media3/session/LegacyConversions.java)
пишет bitmap только в ALBUM_ART и DISPLAY_ICON. Поэтому buildSrc содержит
узкий ASM-преобразователь одного класса/метода: после ALBUM_ART добавляется
ART с тем же уже загруженным bitmap. Выполняется в AGP до D8/R8 для всех
вариантов приложения. Нет дополнительной загрузки/декодирования картинки,
второй системной сессии, reflection в приложении, OEM broadcast или нового
разрешения публикации. Существующая очистка metadata удаляет все три bitmap.

Версия Media3 явно зафиксирована. Несовпадение сигнатуры, аргумента bitmap,
отсутствие единственного места вставки или уже существующий ART прерывают
сборку. Обновление Media3 требует повторного аудита этого решения; если upstream
добавит ART, преобразователь следует удалить, а не применять второй раз.
API Gradle в buildSrc загружается без транзитивного AGP/Kotlin: это избегает
конфликта версии плагина и его Kotlin API с основным version catalog.

## Проверка и пределы

JVM проверяет защиту преобразователя; native-тест получает данные через
android.media.session.MediaController и проверяет Music/Radio, bitmap,
смену трека без обложки и внешние команды. Подписанный APK отдельно проверяется
внешним framework-потребителем и в CWG. Результаты и точный Build фиксируются
в [отчёте beta](PATCH_2_5_2_BETA_VERIFICATION.md).

Beta не меняет stable feeds/latest2.5.1-build98. Приёмка приборной панели
остаётся результатом пользователя, а не выводом по эмулятору.
