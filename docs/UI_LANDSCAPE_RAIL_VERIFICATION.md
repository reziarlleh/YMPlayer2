# Левое меню в альбомной ориентации — build30

Исторический результат build30. По замечанию владельца вид без подписей для
крупного шрифта заменён в [M9.3/build31](M9_3_VERIFICATION.md); актуальный
план — в [ROADMAP](ROADMAP.md).

Дата: 2026-09-26. В build29 короткое широкое окно применяло компактное левое
меню только на главном экране: оставались значки без подписей и заголовка `YM`.
На медиатеке и других страницах в том же окне меню было полным. Это и было
замеченным владельцем несоответствием.

Правило выбора вида меню теперь общее для всех разделов. В обычном альбомном
окне остаются заголовок и подписи; высота пунктов и верхний интервал немного
уменьшены, чтобы все четыре пункта помещались. При высоте менее 380 dp или
масштабе шрифта больше 130% компактный вид включается на всех страницах.
Содержимое самого плеера по-прежнему не прокручивается.

Проверено на `YM2_M1_Phone`, Android 15/API 35, в альбомной ориентации:

- При обычном шрифте плеер и медиатека имеют одинаковый полный rail с четырьмя
  видимыми подписями. Скриншоты итогового подписанного APK:
  [плеер](qa/landscape-rail/normal-player.png),
  [медиатека](qa/landscape-rail/normal-library.png).
- При шрифте 200% компактное меню одинаково на
  [плеере](qa/landscape-rail/font200-player.png) и
  [медиатеке](qa/landscape-rail/font200-library.png). Эти два снимка — debug APK.
- `PlayerCompositionTest#fixedPlayerFitsViewportAndUsesLargerTransport`
  прошёл в альбомной ориентации (`OK (1 test)`): элементы управления в пределах
  экрана, `ScrollBy` у плеера отсутствует. `assembleDebug` и `lintDebug` прошли.

Подписан `2.0.0beta-build30`, `versionCode=30`, SHA-256
