# Ошибочные решения и правила повторного использования

Индекс существующих расследований, сверенный 4 октября 2026 года.
Причины и исправления ниже подтверждены указанными отчётами. Гипотезы,
которые ещё не проверены, хранить в багрепорте с такой пометкой.

| Случай | Неверный подход / причина | Исправление и правило | Подробности |
| --- | --- | --- | --- |
| OAuth, Android15 | Перенос входа расходился с последовательностью рабочего1.x; после браузера показывалась сетевая ошибка | Сначала сопоставить порядок обмена/сохранения/повтора1.x. Код устройства показывать до браузера, токен2.x хранить самостоятельно | [M4.1](M4_1_VERIFICATION.md), [ADR-009](DECISIONS/ADR-009-auth-legacy-parity.md) |
| Аудио при работающем поиске | Лишнее ограничение формы ответа отвергало реальные данные Яндекса | Проверять mapping на реальном протоколе; вымышленные фикстуры не доказывают совместимость | [M5.1](M5_1_VERIFICATION.md) |
| Волна после двух треков | Не полностью перенесены правила ожидания/предзагрузки1.x | Готовить следующий трек во время текущего и корректно ждать продолжение; repeat/shuffle относятся к конечным спискам | [M6.2](M6_2_VERIFICATION.md), [ADR-012](DECISIONS/ADR-012-wave-continuation.md) |
| Огромные списки воспроизведения | Страницы просмотра и полный каталог смешивались с очередью движка | Плейлист хранит порядок ссылок; каталог — индекс и курсор; Media3 получает соседние треки. Не создавать лишние копии метаданных | [ADR-031](DECISIONS/ADR-031-catalog-cursor-not-queue.md), [M11.12](M11_12_VERIFICATION.md) |
| Клип за видеослоем | Compose-controls в release-кандидатах исчезали за видео | Нативные controls и независимая видеосессия; не публиковать неработающий кандидат и не переиспользовать Build | [M9.2](M9_2_VERIFICATION.md), [M9.3](M9_3_VERIFICATION.md) |
| Смена профиля | Поздний restore публиковал metadata и сохранял позицию другого профиля | Проверять поколение/профиль на асинхронных границах, сохранять режимы сразу | [M12.7](M12_7_VERIFICATION.md) |
| Пауза2.2 и канал обновлений | Возврат к старой WIP-ветке мог вернуть неисправленный2.1; beta70 не видна stable-клиенту | Возобновлять от последнего исправленного main; владелец выбрал стабильные выпуски без beta | [История решения](PROJECT_HISTORY_2026_10_04.md), [M14](M14_LOCALIZATION_PLAN.md) |
| Подпись APK на Android10 | Одного GET_SIGNING_CERTIFICATES не хватало для archive PackageManager | Проверить оба signing flags на настоящем signed APK; одинаковый ключ сам по себе не доказывает работу обновлятора | [Patch2.2.2 / B-005](PATCH_2_2_2_VERIFICATION.md) |
| Поиск / ChoiceRow | getFocusedRect из Compose focusProperties повторно запускал тот же поиск фокуса; введено66 | Геометрию читать из событий размещения/фокуса. Проверять переход без active child и selected row; гипотезу IME не выдавать за причину | [ADR-039](ADR_039_CHOICE_ROW_FOCUS.md), [79](PATCH_2_3_4_VERIFICATION.md) |
| Ошибка тестовой подготовки | После удаления кнопки новый пункт уже получил фокус; такой тест не воспроизводил вылет | Разделять дефект приложения и неверную фикстуру; сначала показать падение исходного кода, затем успех исправленного | [Первичный и финальный тест79](PATCH_2_3_4_VERIFICATION.md) |
| Динамический CDN | @main запаздывает относительно релиза, pinned APK может быть актуален | Датировать HTTP-срез, сравнивать источники; выбирать максимум валидного Build и проверять APK отдельно | [Bагрепорт D-001](BUG_REPORT.md), [updater](M12_5_VERIFICATION.md) |
| Документы | Новые заметки добавлялись сверху, но нижние абзацы продолжали называть74/78 текущими, F17/English будущими | Текущий статус/план хранить отдельно от исторических отчётов. Перед закрытием сверять README, guides, карты, bugs и GitHub; иметь общий указатель и журнал | [Сверка04.10](DOCUMENTATION_AUDIT_2026_10_04.md), [правила](../AGENTS.md) |
| Область lint | app lint без checkDependencies не выявил API-зависимость MediaMetadataRetriever.use в library:local | Для оценки minimum включать Android-модули и сравнивать с исходным minimum; отдельно учитывать новые SDK-ошибки и прежние замечания качества | [ОценкаAPI28 / B-009](API_28_FEASIBILITY.md) |

Новая ошибка не ограничивается записью «исправлено»: нужны неверный путь,
фактическая причина, выбранное решение, доказательство и условие, при котором
этот урок следует прочитать перед следующей работой.
