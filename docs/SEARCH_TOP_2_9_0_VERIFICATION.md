# «Топ» и жанровые волны в поиске

19 ноября 2026. Владелец поставил задачу первой для следующего цикла. Жанровая
волна отображается в «Топе» как результат поиска. Нажатие запускает её и
открывает плеер.

[Подписанный 2.9.0-build151](MANUAL_2_9_0_BUILD151.md) · [публикация](RELEASE_2_9_0_VERIFICATION.md).

## Запрос и выдача

YMPlayer2 использует `GET /search/instant/mixed` с параметрами
`type=track,album,artist,playlist,wave`, `page` и `pageSize=20`.
Порядок элементов берётся из `results`, конец списка — из `lastPage`.
На живом анонимном запросе «инструментал» страница 0 отдала HTTP 200 и
19 результатов. Среди них плейлисты, исполнители, альбомы и четыре жанровые
волны. Джаз, рок и барокко пришли с ключами
`micro-genre:jazz-instrument`, `micro-genre:instrumental-rock` и
`micro-genre:baroque`. Страница 1 отдала HTTP 200 и 20 результатов.
Старый `/search?type=all` вернул раздельные каталожные блоки без жанровых волн.
[Смешанный ответ на «инструментал»](https://api.music.yandex.net/search/instant/mixed?type=track,album,artist,playlist,wave&page=0&pageSize=20&text=%D0%B8%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D0%BB).

Запуск передаёт полученные `seeds` в существующий `POST /rotor/session/new`.
Он требует авторизации. Анонимная проба вернула HTTP 401.
Подписи переведены в восьми языковых пакетах.

## Проверки сборки

Сборка приложения и инструментальных тестов прошла. В модуле core прошли
189 JVM-тестов. На Android 15 прошли 18 сценариев, на Android 6 — 4.
Проверены порядок выдачи, загрузка второй страницы, обычные фильтры,
возврат из карточки в «Топ» и запуск жанровой волны с полученным ключом.
Сессия воспроизведения в этих тестах использует тестовую выдачу. Запуск
на реальном аккаунте требует проверки отдельно.

Первый проход показал, что общий каталог успевал выбрать «Треки» перед
открытием поиска Яндекса. «Топ» теперь выбирается при входе в источник,
в том числе после выбора аккаунта. В регрессии офлайн-поиска на Android 6
тест явно закрывает клавиатуру после смены профиля. Для снимка экрана
старых API используется `UiAutomation`, доступный до `PixelCopy`.
