# 2.2.0-build71 — обычное обновление из 2.1.5

Дата: 2026-10-02. Владелец сообщил, что установленное приложение не предлагает
опубликованную 2.2, и уточнил: рабочий продукт продолжается без beta.

## Причина

Build70 опубликован на GitHub и в update/manifest.json как beta, однако
update/stable.json оставался на69. UpdateCoordinator установленной stable69
создаёт UpdateClient(channel="stable"); он читает stable.json и отклоняет
манифест с channel="beta". Поэтому ручная проверка69 корректно показывала,
что обновлений нет. Проверка опубликованного APK/HTTP без проверки канала
установленной версии была недостаточной — ошибка процесса выпуска.

Код2.2 уже находился в main того же reziarlleh/YMPlayer2. Рабочая ветка была
инструментом разработки, не новым продуктом или каналом распространения.
Старая WIP не слита. Пакет dev.petrov.ymplayer2 и сертификат не менялись.

## Исправление

2.2.0-build71: тот же код English/Auto/Russian, channel=stable, новый сквозной
Build71. После публикации APK оба манифеста должны указывать на71,
GitHub Release должен быть обычным latest. Beta70 остаётся историческим выпуском.
В дальнейшем 2.2.x выпускается без beta, если владелец отдельно не изменит правило.

Функциональная проверка локализации и сохранения исправлений2.1:
[M14](M14_VERIFICATION.md), 17 разных сценариев на каждом Android/TV.
Логика плеера, API и UpdateClient не меняется ради исправления публикации.
