# Проверка patch 2.2.2-build74

Дата: 2026-10-02. База — main / 2.2.1-build72, `3583197`.
Обычный стабильный patch того же продукта, package, сертификата и канала.
Основание: [аудит](AUDIT_2026-10-02.md), [багрепорт](BUG_REPORT.md).

## Изменения

- B-001: AIFF исключён по расширениям aiff/aif/aifc и MIME до общего `audio/*`.
  Поддерживаемый WAV с общим MIME по-прежнему принимается по расширению.
- B-002: при старте удаляются только собственные `YMPlayer2-Build.apk` с Build
  не выше установленного. Будущие APK, посторонние файлы и офлайн-кэш сохраняются.
- B-003: координатор обновления хранится в ViewModel, использует application
  context и временно подключённую Activity. Поворот сохраняет состояние и I/O;
  установка откладывается до возврата Activity. Отмена не превращается в ошибку
  источника, временные файлы уникальны. APK проверяется до публикации итогового файла.
- B-004: известные вложенные ошибки обновлятора переводятся контекстно на все
  восемь языков, в том числе после смены языка. Хосты и неизвестные детали сохраняются.
- B-005: Android10 получает оба флага PackageManager для чтения сертификатов
  архива. Сравнение действующих подписей, SHA-256 и проверка пакета обязательны.
- Документация сверена с кодом; проверка generated-переводов добавлена в GitHub CI.

## Обнаруженные ошибки проверочных сценариев

Первый расширенный прогон: [Phone 35/36](qa/audit-2026-10-02/phone-app.txt),
[TV 34/36](qa/audit-2026-10-02/tv-app.txt).
Старый тест очереди искал русскую подпись после смены языка; он использует
постоянный test tag. TV-тест повторно добавлял удалённую папку без новой выдачи
URI-разрешения. Теперь он имитирует разрешение системного picker, как остальные
тесты возвращённой папки. Логика воспроизведения для этих исправлений не менялась.
Следующий прогон дошёл до старых немедленных assertions очереди: операции
с дисковым индексом асинхронны, а Compose idle не ждёт I/O. Тест теперь ожидает
строго тот же порядок/удаление/добавление, затем проверяет результат.

Build73 выявил B-005 до публикации: Android10 не заполнил SigningInfo даже у
правильного `.apk`; расширение `.part` не причина. Исправленный клиент прошёл
проверку того же архива на обеих системах. Build73 не распространяется,
его номер сохраняется как выданный; для публикации выделен Build74.
