# YMPlayer2 2.8.2 — полный состав изменений

Выпуск **2.8.2-build148**, публикация разрешена владельцем 17 ноября 2026.
Тот же подписанный APK без пересборки. Android 6.0 и новее.

- В каждом профиле добавлена настройка **«Старт воспроизведения»: Авто / Выкл / Вкл**.
  Авто — прежнее восстановление состояния, используется по умолчанию. Выкл не
  запускает музыку автоматически и не прерывает уже играющий фон. Вкл продолжает
  выбранный источник при открытии приложения, в том числе при возвращении к
  работающему в фоне плееру, который был на паузе.
- Продолжение сохраняет трек, позицию и очередь волны. Поворот экрана и переходы
  внутри приложения не считаются новым открытием. Обычное переключение профиля
  открывает его плеер на паузе; новая пауза, стоп, смена источника или профиля
  отменяют ожидающий автоматический запуск.
- Исправлен запуск звука при ошибке фоновой подготовки только метаданных волны:
  сохранённого состояния Play больше недостаточно для такого запуска.
  Пересоздание окна клипов сохраняет выбранную пользователем паузу.
- Исправлен переход с сенсорного управления клипами на пульт, включая Android 6:
  первое OK выделяет Play; удержание и отпускание этого нажатия не запускают
  клип и не закрывают окно. Следующее нажатие выполняет действие. Одиночные
  касания кнопок сохраняются.
- Сохранена расширенная диагностика медиакнопок: исходная команда, отправитель
  и фактическое состояние движка. Добавлена запись выбранного режима старта.
- Все новые подписи переведены на восемь языков, актуализированы обе инструкции.
  Сохранены пакет и ключ подписи; обновление поверх предыдущих 2.x сохраняет данные.
