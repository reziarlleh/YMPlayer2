# YMPlayer 2.3.2-build77

В списках появилась команда «Выбрать треки». Отмечайте несколько треков и
добавляйте их в очередь или локальный плейлист. Можно создать новый плейлист
сразу из выбранного. Следующие страницы сохраняют отметки, порядок добавления
соответствует порядку выбора. OK на пульте переключает отметку, «Назад» завершает выбор.

Локальные плейлисты сохраняются одной операцией, без частичного добавления при
ошибке. Только для музыки устройства и USB; Яндекс-треки можно добавить в очередь.
Исходные файлы не меняются. Обновление сохраняет настройки, профили, медиатеку и историю.
