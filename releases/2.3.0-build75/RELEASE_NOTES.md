# YMPlayer 2.3.0-build75

В медиатеке появилась история прослушивания. У каждого профиля свой список
последних 500 треков: повторное прослушивание поднимает трек в начало.
Нажмите на запись, чтобы снова её послушать. Для USB нужен подключённый
носитель; для Яндекса — вход выбранного профиля или доступная офлайн-копия.

В историю попадает только начавшееся воспроизведение. Загрузка следующего трека
волны и восстановление на паузе её не меняют. Очистка требует подтверждения
и не затрагивает файлы, кэш, лайки и плейлисты.

Новые пункты переведены на все восемь языков. Добавлена английская инструкция
пользователя с иллюстрациями; основная страница GitHub остаётся русскоязычной.

Это стабильное обновление того же приложения. Устанавливайте поверх 2.2:
профили, настройки, кэш, плейлисты и очереди сохраняются. 2.2.2-build74 остаётся
доступен в прошлых выпусках. Дальнейшие исправления выходят в линии 2.3.x.
