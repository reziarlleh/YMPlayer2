# Темы YMPlayer 2.1

Встроенные «Гавань», «Олива» и «Серебро» собраны тем же форматом, который
используется для пользовательского импорта. «Оксид» остаётся базовым скином.
Тёмная/светлая палитры каждой темы выбираются в настройках оформления.

| Пакет | Исходники | Характер |
| --- | --- | --- |
| [Гавань](harbor.ymskin) | [manifest](harbor/manifest.json) | Стальной синий и светлая керамика |
| [Олива](olive.ymskin) | [manifest](olive/manifest.json) | Оливковый и известняк |
| [Серебро](silver.ymskin) | [manifest](silver/manifest.json) | Графит и серебро |
| [Шаблон Оксида](oxide-template.ymskin) | [manifest](oxide-template/manifest.json) | Основа для своего оформления |

Для изменения встроенной темы скопируйте папку и задайте собственный `id`:
ID встроенных тем защищены от замены при импорте. ZIP не должен содержать
обёртку-каталог. В корне всегда `manifest.json`.

Упаковка: `python tools/Pack-Skin.py skins/oxide-template my-theme.ymskin`.
Импорт: **Настройки → Скины → Импортировать .ymskin**, затем preview и «Применить».
Предпросмотр можно отменить; приложение хранит собственную копию применённого
пакета, поэтому исходный файл после импорта не требуется.

[Полное руководство](../docs/SKIN_AUTHOR_GUIDE.md) · [Контракт](../docs/SKIN_FORMAT.md).
При распространении собственной темы укажите автора и условия её использования.
