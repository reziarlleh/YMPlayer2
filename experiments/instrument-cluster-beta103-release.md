# YMPlayer 2.5.5beta-build103 — эксперимент для приборной панели

Ручная бета для проверки отображения трека и обложки на приборной панели
TENET T8 с Android 10. На самом TENET исправление ещё не подтверждено.

- Медиауведомление теперь без `media3_group_key`; `subText` содержит альбом
  или радиостанцию. Токен MediaSession, обложка и кнопки сохранены.
- Legacy MediaSession сообщает flags=3 вместо 7: отключено объявление
  изменения очереди, которое плеер не выполнял.
- Проверено на эмуляторах API28 и Android TV API29: системное уведомление,
  метаданные, три кнопки и Pause/Play, фоновое воспроизведение и MediaBrowser.
  Release lint — 0 ошибок.

APK подписан прежним сертификатом и устанавливается поверх YMPlayer 2.x с
сохранением данных. Это **ручной prerelease**: stable update feeds и GitHub
Latest остаются на 2.5.4-build102. У beta versionCode 103, поэтому штатная
установка более старой stable102 поверх неё не сработает; вернуться без
удаления данных можно через будущую stable-сборку с более высоким Build.

Для проверки запустите обычный музыкальный трек с обложкой, затем проверьте
приборку при запуске, Pause/Play и смене трека. Сообщите, какие поля и обложка
появились. Если карточки нет, полезен один отчёт отдельного
[Media Monitor](https://github.com/reziarlleh/YMPlayer2/releases/tag/media-monitor-v1.0.0beta-build1)
для YMPlayer и работающего FMPLAY на том же ГУ; компьютер и ADB не нужны.
